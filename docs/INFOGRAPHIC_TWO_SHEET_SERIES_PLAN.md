# 2枚構成インフォグラフィック設計

作成日: 2026-05-06 JST

目的:
- ハッカソン発表・SNS・提出資料で使える2枚組のまとめ画像を設計する。
- 1枚目で「実験結果」を見せ、2枚目で「構造持続理論と持続報酬」を初見向けに翻訳する。
- 1枚に詰め込みすぎず、結果の説得力と制度思想の理解を両立する。

関連:
- [まとめ画像構成案](./INFOGRAPHIC_CONCEPT_RAW_INSIGHTS.md)
- [持続報酬 説明パック](./SUSTAINABLE_REWARD_EXPLAINER.md)
- [インフォグラフィック素材パック](./INFOGRAPHIC_SOURCE_PACK.md)

## 全体方針

2枚に分ける。

```text
1枚目: 結果編
  何を試して、何が起きたか

2枚目: 理論翻訳編
  なぜ持続報酬が必要なのか
```

1枚に全部入れると、読者が「実験結果なのか、制度案なのか、理論説明なのか」で迷いやすい。

2枚にすると、次の流れが作れる。

```text
実験で何が見えたか
  -> 持続報酬 + 伴走支援が効いた

なぜそれが効くのか
  -> 表層KPIではなく、修復・更新・継承を可能にする深層機能へ報酬を流すから
```

## 1枚目: シミュレーション結果編

### タイトル

制度は、届いて初めて希望になる

### サブタイトル

LLMエージェントによる制度設計シミュレーション

### 主メッセージ

一時金だけでは弱く、持続報酬 + 伴走支援で若者の希望が大きく回復した。

### 役割

- 何を比較したかを見せる。
- 8シナリオの結果を見せる。
- 子ども希望指数と40年目SUMMARYを見せる。
- 伴走支援が効いた理由を見せる。
- AI自動調整の強さと副作用を見せる。
- 住民rowの声で、人間の反応として伝える。

### 入れるパネル

| 番号 | パネル | 内容 |
|---:|---|---|
| 1 | タイトル帯 | 制度は、届いて初めて希望になる |
| 2 | 何を比較したか | 比較基準、一時金、持続報酬、AI自動調整の8シナリオ |
| 3 | 子ども希望指数 | 9% -> 82% / 78% の主結果 |
| 4 | 40年目SUMMARY | 希望・中立・注意・危険の比較 |
| 5 | 伴走支援が効いた理由 | 通知 -> 予約 -> 着金 -> 相談 |
| 6 | 配るだけでは足りない | 一時金のみの限界と政策疲労 |
| 7 | AI自動調整の創発 | 追加より、束ねる・減らす・説明する方向へ |
| 8 | 副作用 | 財政不安、政策疲労、対象外感、手続き疲れ |
| 9 | 住民rowの声 | 生活防衛から制度利用・相談へ |
| 10 | 次の一言 | では、希望を支えた「持続報酬」とは何か？ |

### 画像内コピー

- 若者に、まだ希望が届く制度はある。
- 配るだけでは希望にならない。
- 制度は、使える導線になって初めて届く。
- AIは強いが、副作用も残る。
- 重要なのは、施策生成だけでなく副作用観測と打ち方の制御。

## 2枚目: 持続報酬 / 構造持続理論翻訳編

### タイトル

壊れず、直せて、次へ渡せる社会をつくる

### サブタイトル

構造持続通貨 / 持続報酬の考え方

### 主メッセージ

持続報酬は、よい行動ポイントではない。個人・家系・企業・社会・国家・自然を、自己を維持しながら変化に適応する構造体として見て、修復・更新・継承を可能にする深層機能へ報酬を流す考え方である。

### 役割

- 構造持続理論の深さを、一般向けに翻訳する。
- 表層成果ではなく、深層機能を見ることを示す。
- 個人・家系・企業・社会・国家・自然を同じ問いで見ることを示す。
- 資本主義の何を補完するのかを示す。
- 仮想通貨でもBIでもない、という境界線を大きく見せる。
- 企業拠出型の持続クレジットに展開できることを示す。
- ガードレールを置く。

### 入れるパネル

| 番号 | パネル | 内容 |
|---:|---|---|
| 1 | 先に結論 | 壊れず、直せて、次へ渡せる構造を増やす行動に報酬を流す |
| 2 | 6つの構造体 | 個人・家系・企業・社会・国家・自然を、自己維持しながら変化に適応する構造体として見る |
| 3 | 表層から深層へ | 売上、出生数、相談件数ではなく、その裏にある持続機能を見る |
| 4 | 深層機能モデル | 状態観測、記憶保持、資源変換、信頼整合、修復実行、学習更新、境界管理、再生産・継承 |
| 5 | なぜ資本主義の補完か | 価格がつかないケア、信頼、地域、自然、次世代の希望が壊れやすい |
| 6 | 仮想通貨でもBIでもない | 交換・投機でも、一律給付でもなく、修復・更新・継承への報酬 |
| 7 | 一時金との違い | 一時金は資源余力を増やすが、修復経路や信頼循環を増やすとは限らない |
| 8 | 伴走支援の意味 | 親切ではなく、関係接続系・修復実行系・信頼整合系を起動する導線 |
| 9 | 企業拠出型の展開 | 企業通貨ではなく、監査された持続クレジットとして社会維持へ還元 |
| 10 | ガードレール | 強制しない、批判を罰しない、個人スコア公開しない、LLMに最終決定させない |

### 画像内コピー

- 表層の成果ではなく、深層の持続機能を見る。
- 個人・家系・企業・社会・国家・自然を、同じ問いで見る。
- 配るだけでは、社会は維持されない。
- BIは生活を支える。持続報酬は、生活が成り立つ構造を維持する。
- 仮想通貨でもBIでもない。修復・更新・継承に報酬を流す。
- 伴走支援は、関係接続・修復実行・信頼整合を起動する導線。
- 企業が直接ポイントを配るのではなく、監査された持続クレジットとして扱う。

## 2枚をつなぐ一言

### 1枚目の最後

では、希望を支えた「持続報酬」とは何か？

### 2枚目の冒頭

持続報酬は、一時金の代わりではない。壊れず、直せて、次へ渡せる構造を増やす行動に報酬を流す設計である。

## デザイン方針

2枚は同じシリーズに見えるようにする。

共通:
- 横長16:9
- 多パネル型
- 紙質の背景
- 青系の枠線
- 見出し番号
- 同じキャラクターまたはAIマスコット
- 同じ注意書きスタイル
- 同じフッター帯

色の主役:

| 画像 | 主色 | 印象 |
|---|---|---|
| 結果編 | 青 + 緑 + 紫 | 比較、AI、希望回復 |
| 理論翻訳編 | 緑 + 金 + 紺 | 修復、更新、継承、社会の土台 |

2枚目は、1枚目より少し研究ノート感とシステム図感を強める。

- 中央に8つの深層機能モデルを置く。
- 周囲に個人・家系・企業・社会・国家・自然の事例を配置する。
- 「仮想通貨でもBIでもない」を右上か中央右に大きく置く。
- 企業展開は右下に小さく置き、ガードレール付きで示す。

## 発表での使い方

1枚目で結果を見せる。

```text
一時金だけでは弱く、持続報酬 + 伴走支援で希望が回復しました。
```

2枚目で意味を説明する。

```text
これは単なる給付ではありません。
表層KPIではなく、修復・更新・継承を可能にする深層機能へ報酬を流す制度設計です。
```

最後に転用を示す。

```text
自治体の制度設計だけでなく、企業人事、学校支援、地域政策にも使えます。
```

## おすすめ最終構成

```text
第1枚: 結果編
制度は、届いて初めて希望になる

第2枚: 持続報酬編
壊れず、直せて、次へ渡せる社会をつくる
```

この2枚で、結果の説得力と制度思想の深さを両方出す。
