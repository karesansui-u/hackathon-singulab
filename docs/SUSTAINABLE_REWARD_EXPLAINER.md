## 一文定義

持続報酬とは、社会や組織が壊れずに続くための行動に、ちゃんと報酬が出る仕組みである。

もう少し具体的に言うと、数字や利益を直接出す人だけでなく、部署間の詰まりをほどく人、困っている人を制度につなぐ人、チームの衝突を未然に防ぐ人、子育てや介護や地域を支える人が、その行動でご飯を食べられるようにする設計である。

## 初見向けの説明

いまの経済では、売上、労働時間、短期成果のように価格へ変換しやすいものに報酬が集まりやすい。

しかし、子育てできる環境を残す、介護する人が壊れないようにする、若者が戻れる経路を作る、地域の孤立を防ぐ、制度を使えるように翻訳する、といった活動は、社会を続けるうえで重要なのに報酬化されにくい。

持続報酬は、こうした「壊れる前に守る」「壊れた経路を修復する」「次世代へ渡せる条件を増やす」活動を、制度上の価値として扱うための報酬レイヤーである。

## 大きな狙い: 資本主義の補完

資本主義は、「お金になるもの」を増やす力が強い。

商品、サービス、労働、資本、信用のように価格がつくものを、効率よく動かすことに優れている。

一方で、価格がついていないものは壊れやすい。

たとえば、家族、地域、自然、信頼、ケア、次世代の希望のようなものは、社会を長く保つために必要なのに、短期の利益計算では軽く扱われることがある。

場合によっては、それらを壊した方が利益が出ることすらある。

構造持続通貨は、この欠けたインセンティブを補うための考え方である。

個人、家系、企業、社会、国家、自然を、同じ単一KPIで乱暴に比べるのではない。
同じ問いで見る。

```text
その系は、変化やショックを受けても、
壊れず、直せて、更新できて、
次世代へ渡せる状態を広げているか。
```

この問いに対して、維持可能性を増やす行動にも報酬が入るようにする。

つまり構造持続通貨は、GDPや企業利益を増やすためだけの通貨ではない。
対象となる系が、壊れず、修復でき、更新でき、次世代へ渡せる状態を広げたときに、その価値を計測・記録する仕組みである。

## 市場で報われにくい価値

いまの市場では報われにくいが、社会を続けるために重要な活動がある。

| 領域 | 報われにくいが重要な活動 |
|---|---|
| 個人 | 休息、学び直し、メンタル不調の予防、孤立からの回復 |
| 家系 | 子育て、介護、家計相談、住居安定、負荷分散 |
| 企業 | 人材育成、技能継承、退職予防、部署間調整、信頼回復 |
| 社会 | 防災、教育、地域維持、制度改善、申請支援、孤立予防 |
| 国家 | 長期インフラ、制度信頼、危機対応、次世代投資 |
| 自然 | 自然回復、土壌・水循環・森林・資源循環の維持 |

これらは「善意」や「自己犠牲」のままにされやすい。

構造持続通貨は、これらを社会を維持する仕事として扱い、会計に載せる試みである。

## 補完したい欠点

資本主義は、価格がついたものを効率よく動かす。
しかし、価格がついていないものを壊しやすい。

壊れやすいものは、たとえば次のようなもの。

- 若者が未来に希望を持てること
- 介護する人が壊れないこと
- 企業が人を育てる余力
- 地域、学校、医療の維持
- 自然環境の回復可能性
- 制度への信頼
- 社会の修復経路
- 子どもを迎えたい人が迎えられる条件

特に厄介なのは、次世代にいいものを残したいという気持ちがなくなることである。

短期的には何も壊れていないように見えても、若者が未来を諦め、子育てや介護や地域維持が「損な役割」に見え、制度への信頼が落ちると、社会の修復経路は静かに狭くなる。

持続報酬は、その静かな損傷を放置せず、維持・修復・継承に報酬を流すための設計である。

## 単一KPIにしない

一番大事なのは、単一KPIにしないことである。

出生数だけに報酬を出すと、望まない出産圧力になる。
介護時間だけに報酬を出すと、家族介護の固定化になる。
制度利用件数だけを見ると、書類や相談件数だけが増える。

だから報酬対象は、単純な数ではない。

報酬対象は、どの系の維持可能性を広げ、どの系を壊していないかを同時に見ることである。

```text
出生数ではなく、子どもを迎えられる条件
介護時間ではなく、介護者が壊れない条件
制度利用件数ではなく、必要な人に届き、疲労を増やさない導線
企業利益だけでなく、人材・信頼・更新能力が残る構造
```

構造持続通貨は「良いことポイント」ではない。

どの系を維持し、どの系を壊していないかを同時に見るインセンティブ設計である。

## 表層成果ではなく深層機能を見る

持続報酬で見たいのは、表に出る成果そのものではない。

売上、出生数、相談件数、制度利用件数、健康度、治安、生物数のような数字は重要だが、それだけに報酬を出すと歪みやすい。

本当に見たいのは、その裏にある深層機能である。

| 表層に見えるもの | 深層で見たいもの |
|---|---|
| 売上 | 外部価値を内部資源へ変換する力 |
| 出生数 | 世代をまたいで条件を渡す力 |
| 相談件数 | 関係接続と修復経路 |
| 健康 | 自己調整と回復可能性 |
| 制度利用 | 信頼循環と到達導線 |
| 環境保護 | 生命支持条件の再生成 |

つまり、持続報酬は「何件やったか」ではなく、「壊れず、直せて、更新できて、次へ渡せる構造が増えたか」を見る。

## 深層機能の最小セット

個人、家系、企業、社会、国家、自然は、それぞれ見た目は違う。

しかし、自己を維持しながら環境変化に適応する構造体として見ると、共通して必要な機能がある。

| 深層機能 | やっていること |
|---|---|
| 状態観測系 | 異常を知る |
| 記憶・履歴保持系 | 何を維持し、何を更新すべきかを保つ |
| 資源変換系 | 外部から維持資源を得る |
| 信頼整合系 | 協力を可能にする |
| 修復実行系 | 損傷を回復する |
| 学習更新系 | 変化へ適応する |
| 境界管理系 | 内外を区別し、交換を制御する |
| 再生産・継承系 | 時間を越えて構造を渡す |

持続報酬が流れるべきなのは、これらの深層機能を強くする行動である。

たとえば伴走支援は、単なる親切ではない。
制度と人をつなぐ関係接続系であり、詰まりを直す修復実行系であり、制度不信を下げる信頼整合系でもある。

## 一般向けの比喩

会社には、売上を作る人、技術を作る人、採用する人がいる。

一方で、表の数字には出にくいが、組織が壊れないために重要な人もいる。

- 部署間の誤解をほどく
- 新人が孤立しないよう声をかける
- 忙しい人の詰まりを見つけて調整する
- 制度や手続きを、実際に使えるところまで案内する
- 小さな不満が退職や分断になる前に拾う

こういう行動は、利益にはすぐ出ない。
でも、なかった場合には、退職、炎上、孤立、制度不信、ケア崩壊として後から大きく効いてくる。

持続報酬は、この「なくなると系が壊れる行動」を、見えない善意のままにせず、報酬に変える考え方である。

## ハッカソンでの短い言い方

持続報酬は、社会や組織を壊れにくくする行動で飯が食える仕組みです。

いまの制度や会社では、売上や短期成果は評価されやすい。一方で、チームをつなぐ、制度を使えるようにする、孤立を防ぐ、子育てや介護を支える、という行動は見えにくい。

このデモでは、そうした行動がなかった場合に何が壊れるか、あった場合にどれだけ維持・回復しやすくなるかをシミュレーションし、報酬化できる可能性を見せます。

## 支払いの考え方

系の維持や破壊は、時間がたってから見えることが多い。
一方で、報酬は今日・今月・今年のように支払う必要がある。

そのため、持続報酬は一発で完全精算するより、次の三層に分けると分かりやすい。

| 支払い | 何に払うか | 例 |
|---|---|---|
| 即時報酬 | 効果が高いと事前に分かっている行動 | 声かけ、制度案内、調整、申請支援、休息確保 |
| 予測報酬 | シミュレーション上、崩壊確率を下げる行動 | 退職予防、分断緩和、子育て導線、介護負荷分散 |
| 後日調整 | 実際の結果を見た追加精算 | 年末調整、追加ボーナス、次期係数の見直し |

ハッカソンでは、完全な通貨発行ロジックまで作らなくてよい。

見せたいのは、「すでに見えている数字」だけでなく、「放置すると壊れる構造を守る行動」にも報酬を出せる、という設計思想である。

## どう数値化するか

人間の希望や安心は揺れ動く。
だから、感情そのものをそのまま支払い基準にすると不安定になる。

持続報酬では、感情だけではなく、次のような観測しやすいものに落とす。

| 見たいもの | 例 |
|---|---|
| 行動変化 | 生活防衛から相談、制度利用、参加へ移ったか |
| 離脱予防 | 退職、孤立、申請断念、育児・介護の燃え尽きを防いだか |
| 回復経路 | 困ったあとに戻れる相談先、代替手段、支援導線が増えたか |
| 摩擦低下 | 手続き、予約、説明、部署間調整の詰まりが減ったか |
| 副作用低下 | 対象外感、政策疲労、財政不安、監視感が増えすぎていないか |

さらに、シミュレーションで「その行動がなかった場合」と「その行動があった場合」を比べる。

```text
調整役がいない未来:
  誤解が増える / 退職が増える / 制度が使われない / 孤立が深まる

調整役がいる未来:
  相談につながる / 申請できる / 衝突が減る / 戻れる経路が残る
```

この差分を、持続報酬の候補として扱う。

重要なのは、脳内の感情を直接測ることではない。
観測できる行動、制度利用、離脱、回復経路、副作用と、シミュレーション上の差分を組み合わせて、報酬候補を作ることである。

## 探索フェーズ

最初から完璧に「何が持続最大化行動か」を決め打ちしない。

まず、特定の系について、壊れやすい場所を探す。

企業なら:

- 部署間連携
- 新人定着
- マネージャー負荷
- 退職予兆
- 制度利用の詰まり
- 評価への不満

子育てなら:

- 費用不安
- 手続き離脱
- 産後ケア不足
- 相談先の不在
- 対象外感
- パートナー間の負荷偏り

地域なら:

- 孤立
- 移動手段
- 介護負荷
- 防災
- 窓口アクセス
- 情報の届かなさ

そのうえで、どんな行動が崩壊確率を下げるか、維持・回復可能性を上げるかを探索する。

この探索にLLMエージェントやシミュレーションを使う。

ハッカソンでの見せ方は、ここを精密な会計制度として完成させるのではなく、「見えない維持行動を発見し、報酬化候補にできる」ことを見せる。

## 理論核との対応

ここから下は、発表で必ず話す必要はない。詳しく聞かれたときの裏側説明である。

構造持続理論では、対象を次のように切る。

```text
Pi = (X, G)
```

- `X`: 対象となる系。社会、地域、企業、家族形成環境など。
- `G`: その系が同じ系として続くために保つべき維持条件。
- `V_G`: `G` を満たす、または修復・更新により `G` を回復できる状態・行動・経路の集合。
- `m`: `V_G` の大きさを読むための、事前固定されたものさし。

維持可能領域が縮むと構造消耗 `d_t` が増え、修復や回復で領域が戻ると回復量 `r_t` が増える。

```text
b_t = d_t - r_t
B_n = sum(b_t)
S_n = M_n e^{-B_n}
```

ここで `B_n` は累積純消耗量、`M_n` は有効維持余力である。

持続報酬は、この理論核を制度側に翻訳したものとして読む。

```text
報酬対象:
  B を下げる活動
  r_t を増やす活動
  V_G を広げる活動
  M を守る活動
```

重要なのは、後から都合よく「良い活動」を選ぶことではない。どの系 `X` の、どの維持条件 `G` を守るのか、何を `V_G` と数えるのか、どのものさし `m` で読むのかを、事前に固定する必要がある。

この事前固定がないと、持続報酬はただの補助金、ポイント制度、思想スローガンになってしまう。

- 「通貨」と言うと、仮想通貨、ベーシックインカム、ポイント制度と誤解されやすい。
- 今回の本質は、新しい通貨そのものではなく、社会を支える活動に報酬が流れる設計である。
- 詳細パネルや脚注で、正式名として「構造持続通貨」を出せばよい。

## 何に報酬を出すのか

持続報酬は、「良いことをした人」に雑にポイントを配る制度ではない。

報酬対象に近いのは、事前に指定した系が壊れず、修復され、次世代へ渡せる条件が広がった場合である。

理論語彙に寄せるなら、報酬対象は「活動量」ではなく、維持可能領域 `V_G` の縮小を抑えたこと、または回復経路を増やして累積純消耗量 `B` を下げたことである。

| 系 | 報酬対象になりうる活動 | 見たい成果 |
|---|---|---|
| 個人 | 休息、相談、学び直し、復職支援 | 壊れる前に戻れる経路が残る |
| 家系 | 育児、介護、家計相談、住居安定、代替ケア | 誰か一人に負荷が固定されない |
| 企業 | 若手育成、技能継承、健全なAI導入、配置転換 | 短期利益だけでなく更新能力が残る |
| 社会 | 申請支援、制度翻訳、地域連帯、孤立予防 | 制度不信や撤退が減る |
| 国家 | 防災、教育投資、制度更新、長期インフラ | 危機対応と長期継承が両立する |
| 自然 | 土壌回復、水循環保全、森林再生、資源循環 | 回復不能な損傷を避ける |

子育て文脈では、出産そのものに報酬を出すのではなく、望む人が子どもを迎えられる条件、子ども本人が安全に育つ条件、親や周囲が壊れない条件に報酬を流す。

## 一時金との違い

| 比較 | 一時金のみ | 持続報酬 |
|---|---|---|
| 主な役割 | 初期費用を下げる | 未来の維持条件を広げる |
| 効きやすい不安 | 出産・子育て初期の費用不安 | 継続不安、孤立、制度不信、対象外感 |
| 弱点 | 財源不安、政策疲労、対象外感が残りやすい | 伴走導線がないと希望化しにくい |
| 誤用リスク | ばらまき、短期人気取り | 社会信用スコア化、監視、補助金ゲーム |
| 今回の示唆 | 改善はするが限界がある | 土台になるが、伴走支援と組むと強い |

理論核に合わせると、一時金は主に `M` 側の有効維持余力を一時的に増やす施策として読める。一方、持続報酬は `V_G` の縮小を抑え、`B` を下げる方向の設計である。ただし、伴走支援がないと、本人にとって使える経路が増えず、`V_G` の実効的な拡大まで届きにくい。

## 伴走支援とセットにする理由

持続報酬だけでは、「制度はあるが、自分がどう使えばいいか分からない」状態が残る。

今回のシミュレーションでは、持続報酬に伴走支援を足したときに、若者・家族形成・次世代観測の反応が大きく改善した。

伴走支援が担うのは、次の導線である。

```text
通知 -> 予約 -> 着金 -> 相談 -> 本申込 -> 異議申立/見直し
```

つまり、持続報酬は「社会を支える活動への報酬」であり、伴走支援はそれを「実際に使える制度」に変える導線である。

持続報酬とは？

### パネル本文

社会を続ける活動に報酬を流す仕組み。子育て、介護、地域、学び直し、制度利用支援など、未来の選択肢を残す活動を制度上の価値として扱う。

### 図解案

```text
価格に乗りにくい価値
  子育て環境 / 介護負荷軽減 / 地域の孤立予防 / 学び直し / 制度翻訳
        ↓
持続報酬
        ↓
未来の選択肢が残る / 生活防衛から制度利用へ / 対象外感を緩衝
```

### 強調コピー

- 配るだけでなく、続けられる条件に報酬を流す。
- 出産そのものではなく、子どもを迎えられる条件に支払う。
- 子どもを持つ人だけでなく、社会を支える活動も価値化する。

## 仮想通貨でもBIでもない

ここは、単なる誤解防止ではなく、思想の境界線として前面に出す。

持続報酬は、仮想通貨でもベーシックインカムでもない。

| 比較 | 何をするか | 足りないもの |
|---|---|---|
| 仮想通貨 | 交換、保有、投機、決済に使われやすい | 何を維持するかが決まらない |
| ベーシックインカム | 全員に生活原資を配る | 修復・更新・継承の行動を設計しにくい |
| 持続報酬 | 壊れにくさ、戻れる経路、修復行動に報酬を流す | 副作用観測とガードレールが必要 |

BIは生活を支える。
持続報酬は、生活が成り立つ構造そのものを維持する。

理論寄りに言えば、BIは主に資源側余力 `M` を補う。
一方、持続報酬は維持可能領域 `V_G` を広げ、累積純消耗 `B` を下げる方向を狙う。

発表での言い方:

```text
配るだけでは、社会は維持されない。
維持されるには、壊れる前に気づく人、
つなぎ直す人、直す人、次へ渡す人が必要です。
持続報酬は、その行動に報酬を流します。
```

持続報酬は、次のものでもない。

- 無制限の新しいお金
- ボランティア時間への単純ポイント
- 出産した人だけへの成果報酬
- 介護時間が長いほど得をする歩合制度
- 行政やLLMが「良い人」を採点する社会信用スコア
- 抗議、非出産、休息、制度不信を罰する仕組み

## ガードレール

持続報酬を制度として扱うなら、最低限次を守る。

1. 出産、介護、地域活動を強制しない。
2. 子どもを持たない選択や、制度への批判をマイナス評価しない。
3. 個人単位のスコア公開をしない。
4. LLMに発行額や権利制限の最終決定をさせない。
5. 発行者、評価者、監査者、異議申立窓口を分ける。
6. 反実仮想、対象、維持条件、検証方法を事前登録する。
7. 壊してから直す方が得になる構造を禁止する。
8. 短期成果だけで全額発行せず、遅延検証する。
9. 財源、供給能力、物価、現場負荷を同時に見る。
10. 平均改善で、少数派や対象外層の悪化を隠さない。

## 発表での30秒説明

持続報酬は、社会を支える活動に報酬を流す仕組みです。

お金を配るだけだと、財源不安や手続き疲れが残ります。そこで、子育て、介護、学び直し、地域支援、制度を使えるようにする活動など、未来の選択肢を残す活動を制度上の価値として扱います。

ただし、出産数や介護時間を直接スコア化するのではありません。望む人が子どもを迎えられる条件、介護者が壊れない条件、若者が戻れる経路が広がったかを見ます。だから今回のデモでは、持続報酬に通知・予約・着金・相談の伴走支援を足したときに、若者の希望が大きく立ち上がりました。

## 発表での10秒説明

持続報酬は、社会を続ける活動に報酬を流す仕組みです。出産そのものではなく、子どもを迎えられる条件、介護者が壊れない条件、若者が戻れる経路を価値として扱います。

## Q&A

### Q. これは仮想通貨ですか？

違います。デモでは分かりやすく「報酬」と呼びます。正式設計では、構造持続価値を読む会計単位やクレジットを想定しますが、無制限に円へ交換できる仮想通貨ではありません。

### Q. ベーシックインカムですか？

違います。ベーシックインカムは生活原資を支える発想です。ただし、一律給付だけでは、孤立をつなぎ直す人、制度を使えるようにする人、介護者を壊さない仕組み、若者が戻れる経路が自動で増えるとは限りません。持続報酬は、そうした修復・更新・継承の行動に報酬を流す発想です。

### Q. 出産を促すための報酬ですか？

違います。出産そのものを成果報酬にすると、強制感や対象外感が出ます。持続報酬が見るのは、望む人が子どもを迎えられる条件、子ども本人が安全に育つ条件、親や周囲が壊れない条件です。

### Q. LLMが誰に払うか決めるのですか？

いいえ。LLMは、反応観測、抜け漏れ検出、副作用検出、説明補助に使います。発行額や権利制限の最終決定は、公開された制度設計、監査、人間の異議申立を通す必要があります。

### Q. 企業人事にも使えますか？

使えます。たとえば、短期成果だけでなく、育成、技能継承、退職予防、配置転換、メンタル不調の予防、顧客信頼の維持などを、組織の持続可能領域として評価できます。ただし、従業員監視や忠誠心スコアに崩れないガードレールが必要です。

### Q. 企業が社会に持続PAYを出すのはありですか？

アイデアとしてはありです。ただし、企業が自由に発行し、自由に評価し、自由に使わせる通貨にすると危険です。

安全に寄せるなら、「企業通貨」ではなく「企業拠出型・持続クレジット」として設計する。

```text
企業が原資を出す
  -> 第三者または公開ルールで評価する
  -> 監査された持続クレジットとして発行する
  -> 学び直し、介護、地域支援、相談導線などへ還元する
```

危ない言い方:

```text
企業が社会に持続PAYを発行する
```

安全な言い方:

```text
企業が社会維持活動に拠出し、
第三者検証された持続クレジットとして、
学び直し・介護・地域支援・制度利用導線に還元する。
```

守るべき線:

1. 企業単独で評価しない。
2. 個人スコアにしない。
3. 購買誘導ポイントにしない。
4. 投機対象にしない。
5. 異議申立と監査を置く。
6. 対象外層の悪化を隠さない。
7. 壊してから直す方が得になる構造を禁止する。

## このプロジェクトでの位置づけ

今回のデモでは、持続報酬は単独で万能ではなかった。

観測上の読み筋は次の通り。

1. 一時金のみは、費用不安には効くが、政策疲労や財源不安が残る。
2. 持続報酬のみは、危険層を抑える土台になるが、希望化には足りない。
3. 持続報酬 + 伴走支援では、制度利用と相談が動き、若者・家族形成・次世代観測の反応が良好化した。
4. AI自動調整と組むと強いが、財政不安や手続き疲れも残るため、副作用観測が必要になる。

つまり、勝ち筋は「持続報酬そのものが魔法」ではない。

勝ち筋は、社会を支える活動を価値化し、それを本人が使える導線まで届け、副作用を見ながら打ち方を変えることである。
