# アーカイブ

このディレクトリは、現在の製品仕様の正本ではないが、過去の検討、旧設計、調査メモとして残すものを置く場所。

ここに置くもの:

- 旧世界モデル設計メモ
- 旧プレゼン構成メモ
- 現在の製品パッケージには入れない補助調査
- 参照頻度は低いが消すには惜しい検討資料

ここに置かないもの:

- 現在の製品仕様の正本
- 実行入力の正本
- 生成済みrowデータ
- rawデータ

## 移行方針

旧トップレベルdocsは、現在の製品仕様と混ざらないように用途別ディレクトリへ移動済み。
移動履歴は `移行候補/旧トップレベルdocs一覧.tsv` に残す。

アーカイブ内の文書は、過去検討の保存を優先する。
古いパスや削除済み旧実装への参照が残っている場合があるが、現在の正本ではない。

## 判断ルール

| 判断 | 置き場所 |
|---|---|
| 今後の製品仕様として読む | `docs/製品パッケージ/` |
| 実行に使う入力データ | `domain_packs/{pack_id}/data/` |
| 調査中・根拠整理 | `research/{domain}/` |
| rawデータ | `data_sources/{source}/{snapshot_date}/` |
| 生成済みrow | `outputs/runs/{run_id}/` |
| 旧検討・参照用 | `docs/アーカイブ/` |
