# プレゼン用メモ: なぜ世界設計をここまで現実寄りにするのか

この文書は、`hackathon-singulab` のプレゼン時に、
「なぜ単なるトイモデルではなく、地政学・エネルギー・貿易・制裁・AI進歩シナリオまで埋め込もうとしているのか」
を短く、説得力を持って説明するためのメモである。

## 1. 一言で言うなら

私たちが作りたいのは、単なる未来っぽい物語生成ではなく、
「現実の制約の上で、持続主義が資本主義をどう補完しうるかを試す実験機」である。

そのため、世界設定も適当な架空世界ではなく、

- エネルギー依存
- 貿易依存
- 地政学的対立
- 制裁
- 気候リスク
- AI とフィジカルAIの普及速度差

を持つ現実寄りの世界として設計する。

## 2. なぜリアルな世界設計が必要なのか

このプロジェクトでは、
「構造持続ポテンシャル `S` を通貨化したら社会はどう変わるか」
を見たい。

ただし、その問いは現実の制約がなければ意味を持ちにくい。

たとえば本当に重要なのは、

- その国はエネルギーを自給できるのか
- 食料や鉱物をどこから輸入しているのか
- 制裁や紛争で物流が止まったら何が壊れるのか
- AI によって仕事が消える速度と、制度が適応する速度のどちらが速いのか

である。

つまり、持続主義が効くかどうかは、
理念だけではなく、依存構造やボトルネックの上で試さないと分からない。

## 3. プレゼンで伝えたい核

プレゼンでの中心メッセージは次でよい。

「私たちは、資本主義を捨てるのではなく、価格が取りこぼしている持続に必要な仕事を、別の報酬系で支えたら世界はどう変わるかを見ようとしている。」

そして、その問いを真面目に扱うために、
世界モデルにも次の現実を埋め込んでいる。

- 国ごとのエネルギー条件
- 貿易ネットワーク
- 地政学と制裁
- 気候・災害リスク
- AI進歩の地域差と制度吸収力

## 4. トイモデルとの違い

このシミュレーションは、単に agent が動いて会話するだけではない。
現実寄りの世界設計を入れることで、次の問いが立つ。

- どの国や地域は無介入でどれくらい持続できるか
- どれくらいの期間、どれくらいの支援があれば自走可能になるか
- 国際協力は善意ではなく、相互利得として成立するか
- マネーゲームの勝者は、構造持続に投資することで自分も守れるか
- AI が仕事を奪う速度と制度適応の速度のズレで、どこが先に崩れるか

ここが、単なる未来SFではなく「政策や制度の stress test」として見せられるポイントである。

## 5. こう言うと伝わりやすい

短く話すなら、次の言い回しが使いやすい。

- 「世界をリアルにしているのは、未来予測を当てたいからではなく、持続主義が効く条件と効かない条件を見分けたいからです。」
- 「地政学やエネルギーを入れているのは、社会が理念ではなく依存関係の上に立っているからです。」
- 「AI時代に仕事が消えるなら、次に問うべきは“何で飯が食える世界にするのか”です。」
- 「このモデルでは、その答えを `cash` だけでなく `structure credits` のある二重経済として試しています。」
- 「勝者が持続に投資すると自分も得する設計にしているので、これは慈善モデルではなく、崩壊回避の合理的インセンティブ設計です。」

## 6. 1分版トークトラック

「このプロジェクトは、AI時代に市場が十分に報酬化できないけれど社会の持続に必要な仕事を、どう支えるかを考えるシミュレーションです。
そのために、通常の `cash` に加えて、構造持続への寄与に応じて得られる `structure credits` を入れています。
ただ、それを本当に試すには世界設定が軽すぎてはいけません。
なので、国ごとのエネルギー依存、貿易、制裁、紛争、気候リスク、AI普及速度の差まで入れられる設計にしています。
狙いは未来を当てることではなく、どんな条件なら社会が持ち、どんな条件だと壊れるのかを比較できるようにすることです。」

## 7. 3分版トークトラック

1. 問題設定
   AI とフィジカルAI の進歩で、多くの仕事が市場価格だけでは支えきれなくなる可能性がある。

2. 仮説
   それでも、社会の持続に必要な仕事は消えない。
   むしろ、ケア、調停、冗長化、環境修復、制度改善の重要性は上がる。

3. 提案
   そこで `cash` と `structure credits` の二重経済を導入し、
   「持続に寄与する行動でも生活できる世界」をシミュレーションする。

4. なぜ現実寄りなのか
   それが意味を持つかは、エネルギー、貿易、地政学、制裁、気候、AI普及の地域差を無視すると分からない。

5. 何が見えるか
   どの国がどれだけ持つか、どの介入が自走可能性を作るか、国際協力や勝者の持続投資がどこまで合理的かを比較できる。

## 8. スライドで見せたい絵

- 世界地図や地域ネットワーク上に `S`, `H_x`, `I*_x(H)` を表示する
- 資源 flow と chokepoint を可視化する
- `cash only` と `cash + structure credits` の比較を出す
- `高自動化 × 低適応` と `高自動化 × 高適応` の世界分岐を並べる
- `TRANSFER`, `FRAGILE_GAIN`, `METRIC_HACK` のような赤旗コードで見せかけの改善を示す

## 9. 避けたい見せ方

- 「全部リアルに再現します」と言い切る
- 「未来予測モデルです」と言い切る
- 「AIが全部の仕事を完全に奪う」と断定する

むしろ、こう表現する。

- 「現実の依存構造を持ち込んだ比較実験です」
- 「未来を予言するのではなく、条件分岐を可視化します」
- 「どの制度設計なら壊れにくいかを試します」
