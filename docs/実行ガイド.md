# 実行ガイド

このページは、審査員や開発者が「どこまで動くか」「どう再実行するか」を確認するためのガイドです。

## まず理解すること

このリポジトリには、実行方法が3種類あります。

| 種類 | LLM | 用途 |
|---|---|---|
| 静的デモ再生 | 不要 | 生成済み row をブラウザで見る |
| 本線row生成 | Claude Code CLI / Codex CLI | 国家・組織・個人の閉ループシミュレーションを再生成する |
| 参考LLM実装 | Ollama / Claude / Codex / Gemini | 旧2D空間シミュレータでLLM接続の差し替えを確認する |

現在、シミュレーション作成スタジオはUIモックです。UIからの新規生成は「準備中」で、本線の生成はCLIから実行します。

## 静的デモを見る

GitHub Pages:

```text
https://karesansui-u.github.io/hackathon-singulab/visualization/future_emotion_map.html
```

ローカル:

```bash
python3 -m http.server 8000 --directory public
```

```text
http://127.0.0.1:8000/visualization/future_emotion_map.html
```

この方法は `public/data/runs/` にある生成済み row を読むだけなので、LLM認証やPythonパッケージは不要です。

## Python環境を作る

row を再生成する場合はPython環境を作ります。

```bash
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

## Claude Code CLIで本線を動かす

Claude Code CLI を使う場合は、初回のみ認証します。

```bash
claude login
```

最小確認:

```bash
python3 scripts/run_closed_loop_llm_demo.py \
  --steps 2 \
  --scenario-mode no_intervention \
  --country-codes JPN \
  --organization-ids O02 \
  --agent-ids A01,W01 \
  --model sonnet \
  --output-dir outputs/runs/smoke_claude_no_intervention
```

本線は次の順で1 stepずつ回ります。

```text
国家LLM -> 日本社会状態 -> 組織LLM -> 個人LLM -> 社会フィードバック -> 次step
```

同じ `--output-dir` で再実行すると、完了済み step はスキップされます。途中停止しても再開しやすい設計です。

## Codex CLIで本線を動かす

本線 runner は `--model` が `gpt-` で始まる場合、または `codex` / `codex:{model}` の場合に Codex CLI 分岐を使います。

```bash
python3 scripts/run_closed_loop_llm_demo.py \
  --steps 2 \
  --scenario-mode no_intervention \
  --country-codes JPN \
  --organization-ids O02 \
  --agent-ids A01,W01 \
  --model gpt-5.2 \
  --output-dir outputs/runs/smoke_codex_no_intervention
```

別モデル名を明示する場合:

```bash
python3 scripts/run_closed_loop_llm_demo.py \
  --steps 2 \
  --model codex:gpt-5.2 \
  --output-dir outputs/runs/smoke_codex_custom
```

## AI自動調整シナリオを動かす

AI自動調整系は `policy_search_*` のシナリオです。

```bash
python3 scripts/run_closed_loop_llm_demo.py \
  --steps 2 \
  --scenario-mode policy_search_with_sustain \
  --country-codes JPN \
  --organization-ids O02 \
  --agent-ids A01,W01 \
  --policy-model gpt-5.2 \
  --model gpt-5.2 \
  --output-dir outputs/runs/smoke_policy_search_with_sustain
```

`--policy-model fixture` のままにすると、政策プランナー部分は固定fixtureになり、短時間の確認に向きます。

## ローカルLLMで動かす

Ollama接続は参考実装 [examples/spatial_demo](../examples/spatial_demo/) にあります。これはハッカソン配布の2D空間シミュレータを保存したもので、本線ではなくLLM接続差し替えの確認用です。

```bash
cd examples/spatial_demo
python main.py --config configs/config.smoke.yaml
```

`configs/config.smoke.yaml` は `llm.provider: ollama` です。手元のOllamaに同じモデルがない場合は、`llm.model` を `ollama list` にあるモデル名へ変更してください。

本線の制度設計シミュレーションへローカルLLMを直結するには、`scripts/run_country_llm_demo.py`, `scripts/run_organization_llm_demo.py`, `scripts/run_civilization_os_llm_demo.py`, `scripts/run_policy_planner_llm_demo.py` の model 呼び出し部分へ Ollamaアダプターを追加します。入出力契約は「promptを渡し、JSONオブジェクトを返す」です。

## 他のサブスクCLIで動かす

参考実装側には汎用CLI接続があり、Claude / Codex / Gemini CLI の小規模確認設定があります。

```bash
cd examples/spatial_demo
python main.py --config configs/config.claude.smoke.yaml
python main.py --config configs/config.codex.smoke.yaml
python main.py --config configs/config.gemini.smoke.yaml
```

本線の制度設計 runner は現時点では Claude / Codex 分岐のみです。Geminiなどを本線へ接続する場合は、上記の汎用CLI接続と同じ考え方で、各 `run_*_llm_demo.py` にアダプターを追加します。

## 代表的なシナリオ

| `--scenario-mode` | 内容 |
|---|---|
| `no_intervention` | 追加施策なし |
| `birth_grant_only` | 子育て初期一時金1000万円中心 |
| `structure_intervention` | 構造持続通貨・構造支援 |
| `structure_birth_grant_package` | 構造支援 + 一時金・産後・復帰支援 |
| `structure_hope_family_package` | 構造支援 + 家族形成の伴走支援 |
| `policy_search_no_sustain` | 構造持続なし + AI自動調整 |
| `policy_search_with_sustain` | 構造持続あり + AI自動調整 |
| `policy_search_with_sustain_hope_family` | 構造持続 + 伴走支援 + AI自動調整 |

## 主な出力

`outputs/runs/{run_id}/` に保存されます。

| ファイル | 内容 |
|---|---|
| `country_turns.tsv` | 国家エージェントの反応 |
| `organization_turns.tsv` | 組織エージェントの反応 |
| `agent_turns.tsv` | 個人エージェントの感情・内心・会話・行動 |
| `agent_feedback.tsv` | 集団反応の集約 |
| `japan_state.tsv` | 日本社会状態 |
| `scheduled_events_used.tsv` | 個人LLMに実際に渡した予定イベント |
| `policy_planner_turns.tsv` | AI自動調整シナリオの政策プランナー出力 |
| `raw/` | LLM生レスポンス |
| `run_log.tsv` | 各phaseの実行ログ |
