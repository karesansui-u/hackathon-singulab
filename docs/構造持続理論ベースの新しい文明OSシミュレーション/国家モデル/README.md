# 国家モデル

このディレクトリは、国家LLMエージェントを「若者・現役世代の未来感情シミュレーション」に接続するための素材置き場。

旧 `World Demo` 系のルールベース実装、シナリオ、ビューア、生成物は削除済み。
現在の正本は、国家LLMの入力TSVと、世界イベントから日本社会状態を作る接続パイプラインである。

## 現行資産

| 種類 | 場所 | 役割 |
|---|---|---|
| 国家初期値 | `国家エージェント初期値.tsv` | 制度容量、同盟支援、国内不安、戦争圧力、日本波及係数など |
| 国家目的重み | `国家エージェント目的重み.tsv` | 国家ごとの目的関数の差 |
| 目的関数定義 | `国家目的関数定義.tsv` | 国家構造の存続、社会安定、技術主権などの定義 |
| 世界イベント | `世界イベント24ステップ.tsv` | 24ステップ分の世界イベント候補 |
| 接続設計 | `国家から若者への接続設計.tsv` | 国家状態が日本の若者・現役世代へ効く経路 |
| LLM設計 | `国家LLMモデル設計.md` | 国家エージェントの入力・出力方針 |
| 閉ループ設計 | `完全相互創発システム設計.md` | 国家、日本状態、現役、若者、フィードバックの接続 |
| 日本社会フィードバック | `日本社会フィードバックループ設計.md` | 若者・現役の反応を社会状態へ戻す方針 |
| 自動イベント設計 | `自動イベント生成設計.md` | 国家LLM出力からイベントを検出する方針 |

## 整理方針

この配下は、AGI若者日本ドメインパック化前の国家モデル素材として扱う。

実行入力の正本に昇格したものは、最終的に次へ移す。

```text
domain_packs/agi_youth_japan/data/
domain_packs/agi_youth_japan/prompts/
domain_packs/agi_youth_japan/scenarios/
```

過去の調査・旧実装メモは `docs/アーカイブ/` に退避する。
生成済みrowデータは `outputs/runs/` に置き、`docs/` には置かない。

## LLM化の最小単位

最初から30か国すべてをLLM化しない。

まずは、次のどちらかで始める。

| 構成 | 国数 | 用途 |
|---|---:|---|
| 最小デモ | 8か国/地域 | 発表用。若者への外圧が見えればよい |
| 現実寄り小規模 | 12か国/地域 | 地政学、エネルギー、半導体、同盟を最低限表現 |

推奨は `12か国/地域`。

## 若者レイヤーへの接続

国家モデルは、若者エージェントへ直接「命令」しない。
各ターンで日本社会にかかる外圧を作り、それを若者・現役世代の状態更新に渡す。

| 外圧変数 | 若者・現役世代への影響 |
|---|---|
| 地政学リスク | 不安、制度信頼低下、長期計画の延期 |
| エネルギー価格圧力 | 生活コスト上昇、子ども意向低下 |
| 半導体・計算資源制約 | AI利用格差、進路不安、雇用不安 |
| 安全保障財政圧力 | 税・社会保険負担、教育・子育て予算との競合 |
| 世界景気後退圧力 | 求人減少、非正規化、初期キャリア不安 |
| SNS地政学注目度 | 不安増幅、怒り、裏切られ感 |

## 生成される中間出力

`scripts/build_world_to_japan_state.py` により、国家LLM出力から次を生成する。

| 出力 | 役割 |
|---|---|
| `outputs/runs/country_llm_smoke/japan_state.tsv` | 各ステップの日本社会状態。若者LLMへの社会状況入力 |
| `outputs/runs/country_llm_smoke/auto_events.tsv` | 戦争、間接衝突、エネルギー価格、財政制約などの自動イベント |

この段階では、完全自由生成ではなく、国家LLMの出力をイベント検出器で変換する。
発表デモではこのほうが説明しやすく、暴走しにくい。
