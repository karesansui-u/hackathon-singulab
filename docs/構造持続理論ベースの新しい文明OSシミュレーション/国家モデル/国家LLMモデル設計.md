# 国家LLMモデル設計

## 目的

世界国家エージェントは、若者の未来感情を直接決める存在ではない。
役割は、AGI時代の世界イベントと世界圧力を生成すること。

```text
世界国家エージェント
  -> 日本への世界圧力
  -> 現役世代の制度・経済運用
  -> 若者の未来感情・行動
```

## 既存World Demoとの違い

| 項目 | 既存World Demo | LLM国家モデル |
|---|---|---|
| 主体 | 国家ノード | 国家エージェント/政治委員会 |
| 更新 | ルールベース中心 | LLM推論 + 数値制約 |
| 出力 | S、L、戦争圧力、国内不安 | 国家判断、外交発言、国内向け説明、世界圧力変数 |
| 用途 | 世界構造のシミュレーション | 若者UIへ渡す世界イベント生成 |

## 国家エージェントに持たせる属性

| 属性 | 意味 |
|---|---|
| 国家コード | USA、CHN、JPNなど |
| 政体・制度容量 | 危機時に制度で吸収できるか |
| 同盟関係 | 支援・抑止・制裁の経路 |
| 資源依存 | 原油、ガス、食料、半導体、計算資源 |
| AI自動化影響 | 雇用・格差・生産性への圧力 |
| 国内不安 | 抗議、暴動、政権安定性 |
| 戦争圧力 | gray-zone、proxy、limited war |
| 日本への波及係数 | 日本の物価、雇用、安全保障、SNS不安にどれだけ効くか |

## LLMに出させるもの

各ターン、各国家に次を出させる。

| 出力 | 内容 |
|---|---|
| 国家判断 | このターンの基本方針 |
| 外交行動 | 協力、制裁、圧力、軍事姿勢、交渉 |
| 国内向け説明 | 国民にどう説明するか |
| 本音/制約 | 実際には何に縛られているか |
| 日本への世界圧力 | 日本の若者・現役世代へ効く圧力 |
| リスク段階 | 平時、圧力上昇、境界的圧力、間接衝突、限定戦争 |

## 推奨プロンプト構造

LLMに渡す情報は命令ではなく、状態情報として渡す。

```text
あなたは国家モデルの1ターン推論器。
次の国家状態、直前ターン、世界イベント、依存関係を踏まえ、
国家の自然な判断をJSONで出す。
```

出力例:

```json
{
  "country": "JPN",
  "turn": 6,
  "stance": "防衛費と生活支援の両立を模索",
  "foreign_action": "米国との協議を強め、エネルギー調達先を分散する",
  "domestic_message": "安全保障環境は厳しいが、生活支援も維持する",
  "private_constraint": "財政余力が薄く、若者支援と防衛費が競合している",
  "japan_pressure": {
    "geopolitical_risk": 0.62,
    "energy_price_pressure": 0.55,
    "labor_market_uncertainty": 0.48,
    "fiscal_pressure": 0.58,
    "sns_anxiety_amplification": 0.50
  }
}
```

## 国数

最初は12ノードでよい。
30か国以上は、LLMコストと解釈負荷が大きく、若者UIの発表目的からは過剰。

段階:

| 段階 | 国数 | 目的 |
|---|---:|---|
| Smoke | 5 | 米中日台イランなど、LLM出力形を見る |
| Demo | 12 | 若者への主要な世界圧力を生成 |
| Realism | 30/32 | 既存World Demoと統合 |
| Research | 50 | 国際比較・長期実験 |

## 若者へのインパクトを見る指標

| 世界側出力 | 若者側への主な作用 |
|---|---|
| geopolitical_risk | 不安、長期計画困難 |
| energy_price_pressure | 生活コスト、子ども意向低下 |
| labor_market_uncertainty | 希望指数、自己効力感低下 |
| fiscal_pressure | 制度信頼、裏切られ感 |
| sns_anxiety_amplification | 不安・怒りの増幅 |
| japan_policy_buffer | 安心、希望、連帯感の回復 |
