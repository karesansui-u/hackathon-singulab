# 完全相互創発システム設計

## 目的

発表時のデモは、事前に生成したrowデータを再生する。
ただしrowデータ生成時は、こちらが望む結論を命令するのではなく、国家・日本社会・現役世代・若者の状態を入力し、それぞれのLLMエージェントが自然に反応した観測結果として保存する。

この設計の狙いは、次の閉ループを作ること。

```text
国家エージェント
  -> 世界圧力
  -> 日本社会状態
  -> 現役世代・若者エージェント
  -> 行動集約
  -> 日本社会状態へ反作用
  -> 次ステップの国家・日本・個人状態へ継承
```

## レイヤー

| レイヤー | 役割 | 第一目的/観測対象 |
|---|---|---|
| 世界国家エージェント | 世界イベントと地政学圧力の生成 | 国家構造の存続、正統性、安全保障、技術主権、構造持続余力 |
| 日本社会状態 | 世界圧力と国内反作用の集約 | 地政学、物価、雇用、計算資源、財政、SNS不安、政策緩衝 |
| 現役世代エージェント | 制度・経済・ケア・労働の運用層 | 生活維持、家族責任、制度利用、支援要求、撤退/参加 |
| 若者エージェント | 未来持続の観測層 | 未来感情、自己効力感、希望、子ども意向、行動 |
| フィードバック集約器 | 個人行動を社会圧へ変換 | 撤退圧、制度要求、生活防衛、学習移行、連帯、情報過敏、ケア圧 |

## 1ステップの更新順

| 順番 | 処理 | 入力 | 出力 |
|---:|---|---|---|
| 1 | 国家LLM推論 | 国家初期値、目的重み、前ステップ国家状態、世界イベント | `country_turns.tsv` |
| 2 | 世界から日本への集約 | `country_turns.tsv`、日本波及係数 | `japan_state.tsv`、`auto_events.tsv` |
| 3 | 国内フィードバック合成 | 前ステップの `agent_turns.tsv`、`japan_state.tsv` | `japan_state_feedback.tsv`、`auto_events_with_feedback.tsv` |
| 4 | 現役・若者LLM推論 | エージェント属性、前ステップ個人状態、`japan_state_feedback.tsv`、イベント | `agent_turns.tsv` |
| 5 | 行動フィードバック集約 | `agent_turns.tsv`、人口重み、発信影響重み | `agent_feedback.tsv` |
| 6 | 次ステップ記憶化 | 国家状態、個人状態、社会フィードバック | 次ステップ入力 |

## ファイル構成

推奨出力先:

```text
outputs/runs/closed_loop_llm_24steps/
  manifest.json
  country_turns.tsv
  japan_state.tsv
  auto_events.tsv
  japan_state_feedback.tsv
  auto_events_with_feedback.tsv
  agent_turns.tsv
  agent_feedback.tsv
  run_log.tsv
  raw/
    country_step_001/
    agent_step_001/
    country_step_002/
    agent_step_002/
```

## 主キー

| ファイル | 主キー | 補足 |
|---|---|---|
| `country_turns.tsv` | `step + country_code` | 国家状態の時系列 |
| `japan_state.tsv` | `step` | 世界圧力を日本社会へ集約 |
| `auto_events.tsv` | `step + イベントID` | 世界起点イベント |
| `agent_turns.tsv` | `step + agent_id` | 現役・若者の観測row |
| `agent_feedback.tsv` | `step` | 個人行動の社会圧集約 |
| `japan_state_feedback.tsv` | `step` | 世界圧力に国内反作用を加えた日本状態 |
| `auto_events_with_feedback.tsv` | `step + イベントID` | 世界起点イベントと国内反作用イベントの統合 |
| `run_log.tsv` | `step + phase` | 各処理の開始時刻、終了時刻、秒数、成否 |

## 状態継承

国家側:

- 前ステップの `risk_stage`
- `stance`
- `foreign_action`
- `domestic_message`
- `private_constraint`
- 日本への圧力8指標
- `japan_impact_summary`

個人側:

- 前ステップの `evaluation`
- `emotion`
- `pathway`
- `support`
- `intensity`
- `action`
- `action_category`
- `action_detail`
- `memory_update`
- `carryover_concern`

どちらも命令ではなく、前ステップから残っている観測状態として渡す。

## 重要な制約

- LLMへ「怒らせる」「希望を持たせる」「戦争を起こす」と命令しない。
- 入力は属性、状態、イベント、前ステップ記憶に限定する。
- LLM出力は観測rowとして保存する。
- 発表画面ではLLMを呼ばず、生成済みrowデータだけを再生する。
- 24ステップ生成時は、可能なら1ステップずつ回す。長い未来を一括生成すると、後から整った物語になりやすい。

## 最小実装

すでにある部品:

- `scripts/run_country_llm_demo.py`
- `scripts/build_world_to_japan_state.py`
- `scripts/run_civilization_os_llm_demo.py`
- `scripts/build_agent_feedback_loop.py`

追加した入口:

- 国家側: `run_country_llm_demo.py --stateful --previous-country-turns-tsv ...`
- 個人側: `run_civilization_os_llm_demo.py --stateful --previous-agent-turns-tsv ...`

次に作る実行器は、各ステップでこれらを順番に呼び、TSVを追記・再集約するだけでよい。

## 24ステップ生成コマンド

軽量確認版:

```bash
python3 scripts/run_closed_loop_llm_demo.py \
  --steps 24 \
  --country-codes JPN,USA,CHN,TWN \
  --agent-ids A04,A13,A16,W12,W25 \
  --country-budget 0.30 \
  --agent-budget 0.30 \
  --timeout 420 \
  --output-dir outputs/runs/closed_loop_llm_24steps_light
```

本番候補版:

```bash
python3 scripts/run_closed_loop_llm_demo.py \
  --steps 24 \
  --country-codes USA,CHN,JPN,TWN,KOR,RUS,UKR,IRN,ISR,SAU,IND,EU \
  --agent-ids A04,A13,A16,W12,W25 \
  --country-budget 0.50 \
  --agent-budget 0.50 \
  --timeout 600 \
  --output-dir outputs/runs/closed_loop_llm_24steps
```

より人物ごとの独立性を強めたい場合だけ、個人側に `--parallel-by-agent` を付ける。
ただしClaude呼び出し回数が増えるため、まずは付けずに生成して、出力が均質すぎる場合に使う。
