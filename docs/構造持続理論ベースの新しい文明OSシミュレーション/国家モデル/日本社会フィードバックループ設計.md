# 日本社会フィードバックループ設計

## 目的

若者・現役世代エージェントは、世界外圧を受け取るだけの観測者ではない。
不安、撤退、生活防衛、抗議、学習、連帯といった行動は、日本社会の制度応答や次ステップの社会状態に戻る。

```text
世界国家LLM
  -> 日本社会状態
  -> 若者・現役世代LLM
  -> 行動集約
  -> 日本社会状態へフィードバック
```

## 初期実装の考え方

最初は、若者・現役世代の発言内容をもう一度LLMで自由解釈せず、出力済みの `action_category`、`emotion`、`evaluation`、`intensity` を集計してフィードバック量に変換する。

これにより、デモ中に「なぜ社会状態が変わったか」を説明しやすくする。

## 集約する内部圧力

| フィードバック圧力 | 主な入力行動 | 社会への戻り方 |
|---|---|---|
| 撤退圧力 | 回避・縮小、撤退、危険感情 | 雇用不確実性とSNS不安を上げ、緩衝政策余力を下げる |
| 制度要求圧力 | 抗議・発信、怒り、裏切られ感、制度利用 | 財政圧力と制度応答を同時に押し上げる |
| 生活防衛圧力 | 生活防衛、相談、制度利用 | 生活コスト不安と支援需要を上げる |
| 学習移行圧力 | 学習・就活 | 雇用不確実性を下げ、緩衝政策余力を少し上げる |
| 連帯圧力 | 参加・連帯、連帯感、良好評価 | SNS不安を下げ、緩衝政策余力を上げる |
| 情報過敏圧力 | 情報収集、高い感情強度 | SNS不安と地政学リスクの体感を少し上げる |
| ケア圧力 | ケア継続、ケア責任層の危険感情 | 財政圧力と制度要求を上げる |

## 反映先

フィードバックは同じステップではなく、次ステップの日本社会状態に反映する。

```text
ステップtの若者・現役行動
  -> ステップt+1の日本社会状態を補正
```

## 重要な考え方

このフィードバックは「世界を変える」ほど大きくしない。
戦争や原油価格のような外生圧力は国家レイヤーが作る。
若者・現役世代の行動は、日本国内の制度応答、社会的信頼、SNS不安、学習移行、撤退傾向に効く。

構造持続OSの効果を見たい場合は、ここに政策介入を入れる。

```text
同じ世界外圧でも、
撤退が増える社会では希望経路が閉じる。
連帯・学習・制度利用が報酬化される社会では、希望経路が残る。
```
