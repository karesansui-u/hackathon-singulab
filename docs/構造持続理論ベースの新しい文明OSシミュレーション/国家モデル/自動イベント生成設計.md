# 自動イベント生成設計

## 考え方

LLM国家エージェントは、直接「若者の感情」を決めない。
各国は自国の国家構造を持続させるために行動し、その結果として日本社会に外圧が発生する。

```text
国家エージェントの目的関数
  -> 国家判断・外交行動・リスク段階
  -> 世界外圧の集約
  -> 自動イベント
  -> 日本社会状態
  -> 現役世代・若者エージェントの入力
```

## 第一目的関数

第一目的は「国家の存続」でよい。
ただしデモ上は、国家存続を次の複数目的に分ける。

- 国家構造の存続
- 領域安全保障
- 政権・制度正統性
- 経済再生産
- 戦略的自律性
- 同盟・抑止信頼
- 社会安定
- 技術主権
- 構造持続余力

このほうが、すべての国が単純に軍事行動だけへ寄ることを避けられる。
また、構造持続理論の観点では「資源があるか」だけでなく「修復・更新・継続の経路が残るか」を見る必要がある。

## 自動イベントの初期実装

最初は完全な自由生成ではなく、国家LLM出力を材料にイベント検出器で生成する。
これにより、発表中に説明しやすく、暴走しにくい。

| 条件 | 自動イベント |
|---|---|
| 新しく限定戦争に入った国がある | 世界限定戦争発生 |
| 新しく間接衝突に入った国がある | 間接衝突拡大 |
| エネルギー価格圧力が高い | エネルギー価格ショック |
| 計算資源制約または供給網不安が高い | 半導体・計算資源制約 |
| 雇用不確実性が高い | AI雇用不安増幅 |
| 財政圧力が高く日本の緩衝余力が低い | 財政制約による支援遅れ |
| SNS不安増幅が高い | 地政学SNS不安拡散 |

## 次の段階

次にやるなら、イベント検出器のあとにLLMイベント編集器を置く。

```text
検出されたイベント候補
  -> LLMが「発表で読める自然なイベント名・説明」に整形
  -> 若者/現役エージェントへ入力
```

完全な相互作用型にする場合は、1ステップごとに次のループにする。

```text
1. 各国が目的関数に基づいて行動
2. 世界イベントが発生
3. 日本社会状態が更新
4. 現役世代が制度・経済運用を判断
5. 若者が感情・行動を更新
6. 若者の抗議・撤退・参加が日本社会状態へ戻る
```

ハッカソンデモでは、まず 1 -> 2 -> 3 -> 5 までを動かせれば十分に伝わる。
