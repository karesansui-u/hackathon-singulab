# 構造持続通貨設計

## 目的

この設計の目的は、良い活動にポイントを配ることではない。
目的は、指定した系の構造持続性を高めること自体を、仕事、報酬、通貨発行の基準にすることである。

通常の通貨は、労働、商品、サービス、信用、税、負債などを媒介する。
構造持続通貨では、これに加えて、社会や組織が将来も続けられる経路をどれだけ残したか、壊れた経路をどれだけ修復したか、次世代へ渡せる条件をどれだけ広げたかを価値単位として扱う。

この文書は、正式な計算方法を確定するものではない。
まず置くべきなのは、個人、家系、企業、社会、国家、自然を、それぞれ構造維持問題として読み、どの系の持続性を最大化したら価値が発生するのかを設計するための仮説である。

## 資本主義をどう補完するか

資本主義は、交換可能な財・サービス・労働・資本を価格へ変換するのが強い。
一方で、次のような価値は価格に乗りにくい。

- 子どもや若者の未来経路を残すこと
- 家族や地域のケアを壊さないこと
- 制度不信や社会的撤退を防ぐこと
- 自然環境やインフラの回復可能性を残すこと
- 企業や組織が短期利益のために育成・継承経路を壊さないこと
- まだ壊れていない構造を壊さないよう保守すること

構造持続通貨は、資本主義を置き換えるというより、価格だけでは拾えない「維持・修復・継承・回復可能性」を、別の価値発行レイヤーとして追加する構想である。

```text
既存通貨:
  交換価値、収益性、希少性、信用を媒介する

構造持続通貨:
  維持可能領域、修復経路、次世代継承、回復可能性を媒介する
```

したがって、構造持続通貨はプラスの発行だけでは完結しない。
指定した系の持続可能領域を極端に落とす行為には、負のnat、課徴、担保没収、発行停止、将来発行枠の減額などのペナルティが必要になる。

ただし、発行やペナルティより前に、必ず守るべき憲法的なガードレールがある。
これを置かないと、構造持続通貨は、補助金ゲーム、社会信用スコア、政治的罰則、または強い主体による価値定義の独占へ崩れる。

## 基本発想

構造持続理論では、対象を構造維持問題として読む。

```text
Pi = (X, G)
```

- `X`: 対象となる系。社会、地域、企業、学校、制度、家族形成環境など
- `G`: その系が同じ系として続くための維持条件
- `V`: `G` を満たす、または修復・更新により `G` を保てる状態、行動、経路の集合
- `m`: `V` の大きさを読むものさし
- `M`: 資源側の有効維持余力
- `B`: 回復込みの累積純消耗量
- `S = M e^{-B}`: 構造持続ポテンシャル

通貨化したいのは、単なる活動量ではなく、

```text
系の構造持続ポテンシャル S を上げた量
または
累積純消耗量 B を下げた量
```

である。

## 多層の系を同じ座標で読む

この構想の重要点は、社会だけを対象にしないことである。
個人、家系、企業、社会、国家、自然を、それぞれ `Pi=(X,G)` として切る。

| 系 | 維持条件Gの例 | 持続最大化として価値になること |
|---|---|---|
| 個人 | 健康、学習、役割、関係、自己効力感が維持される | 病む前に休める、学び直せる、役割を持ち直せる |
| 家系 | 生活、ケア、子育て、住居、世代継承が維持される | 介護や育児で誰かが潰れない、子どもを迎えられる |
| 企業 | 価値提供、顧客信頼、人材育成、更新能力が維持される | 短期利益だけでなく、技能継承や健全な事業転換を行う |
| 社会 | 参加、制度信頼、役割分配、修復経路が維持される | 失業・病気・災害後に戻れる経路を増やす |
| 国家 | 安全保障、財政、制度正統性、社会安定が維持される | 分断を抑え、長期投資と制度更新を両立する |
| 自然 | 生態系、水、土壌、気候、資源循環が維持される | 回復不能な損傷を避け、再生可能な利用に戻す |

このとき、通貨発行の対象は「誰かが良いことをしたか」ではなく、
指定した系の維持可能領域を広げたか、縮小を防いだか、修復経路を増やしたかである。

## 崩壊防止の優先順位

構造持続通貨は、単純な総和最大化にしてはいけない。
まず崩壊させてはいけない下限を守り、そのうえで持続性を増やした分だけを価値化する。

優先順位は次の順に置く。

| 優先 | 原則 | 意味 |
|---:|---|---|
| 1 | 権利床・不可逆損傷禁止 | 権利侵害、不可逆自然損傷、強制的な排除は他の改善で相殺しない |
| 2 | 統治分離 | 発行者、評価者、監査者、ペナルティ執行者を分ける |
| 3 | 反実仮想の事前登録 | baseline、G、V、m、時間地平、検証方法を後出ししない |
| 4 | レイヤー別下限 | 個人、家系、社会、自然など保護レイヤーの床割れを許さない |
| 5 | 分布下限 | 平均改善で脆弱層や少数派の悪化を隠さない |
| 6 | 追加性と自己原因除外 | 壊してから直して報酬を取る構造を禁止する |
| 7 | 遅延検証 | 長期価値は仮発行にし、後続副作用を見て確定する |
| 8 | 通貨信用管理 | 発行上限、財源、償還条件を持ち、発行候補と実通貨を分ける |

この順序では、価値を増やす前に「壊してはいけないもの」を守る。
したがって、どこかの系の持続性を上げても、権利床、不可逆損傷、少数派保護、反実仮想事前登録を破った場合は、発行候補から外れる。

## 科学・LLM・自動化の役割

「誰が価値を決めるのか」という問いに対して、答えを一つの主体に集めてはいけない。
科学、LLM、技術進歩、自動化は、価値判断を独占するためではなく、価値判断の恣意性を減らし、検証可能にするために使う。

```text
価値の前提:
  公開レジストリと影響当事者を含む制度プロセスで固定する

計測:
  科学・統計・実証研究で反証可能にする

反応観測:
  LLMエージェントで多様な主体の感情、行動、副作用を観測する

監査:
  自動化されたledger、再現run、異常検知でゲーム化を検出する

異議申し立て:
  独立した人間の審査と救済プロセスを残す
```

LLMに任せてよいのは、反応仮説、抜け漏れ検出、シナリオ生成、説明補助、監査補助である。
LLMに任せてはいけないのは、権利制限、ペナルティ執行、通貨発行額の最終決定、家族形成や政治的発言の評価である。

科学に任せてよいのは、観測指標、比較方法、信頼区間、再現性、支持/非支持の判定である。
科学に任せてはいけないのは、社会が何を守るべきかという価値前提を、当事者抜きで決めることである。

自動化してよいのは、ログ照合、二重計上検出、後出しbaseline検出、指標ゲーム化の警告、発行保留フラグである。
自動化してはいけないのは、個人単位のスコア公開、権利制限、ペナルティ確定、支援拒否である。

実行用の役割分担候補は `domain_packs/agi_youth_japan/data/structure_sustain_automation_roles.tsv` に置く。

## 金融システムとの関係

構造持続通貨は、無制限に新しい購買力を発行する仕組みではない。
ここを混同すると、構造持続価値を測れても、金融側の系を壊す。

まず分けるべきなのは、`nat` と `円` である。

```text
nat:
  構造持続価値を読む会計単位

円:
  実際に財・サービスを買う決済通貨
```

`nat` をいきなり円と1対1で無制限交換できる通貨にしてはいけない。
円給付は、財源、供給能力、インフレ率、価格転嫁、金融安定の制約の中で行う。

安全な設計では、次のレイヤーを分ける。

| レイヤー | 役割 |
|---|---|
| nat会計 | どの活動が構造持続価値を生んだか測る |
| natクレジット | 将来の給付、税控除、公共調達、優先利用権に使える候補 |
| 円給付 | 実際の所得保障。財源と発行上限が必要 |
| サービス給付 | 保育、介護、医療、住居、教育などの現物・利用枠支援 |
| ペナルティ財源 | 構造を壊した外部不経済から回収し、修復に使う |

インフレ対策の基本は、お金だけ増やさないことである。
保育、介護、医療、住居、教育のように供給制約がある分野では、現金だけを増やすと価格が上がりやすい。
その場合は、保育士・介護士の賃金改善、住宅供給、医療アクセス、代替ケア枠、地域交通、申請負荷低下など、供給能力そのものを増やす投資へ寄せる。

金融もまた、構造持続の対象となる系である。
信用、物価、財政、家計債務、地域金融が床割れするなら、構造持続通貨の発行は成功ではない。
つまり、構造持続通貨は金融システムを外側に置くのではなく、金融を含めた系の持続性を観測する。

```text
構造持続価値が増えているように見える
しかし、物価、債務、財政、供給制約が悪化している
ならば、それは発行ではなく乖離監査の対象である
```

実行用の金融ガードレール候補は `domain_packs/agi_youth_japan/data/structure_sustain_finance_rules.tsv` に置く。

## 乖離を測ることで不正を見つける

構造持続通貨が既存の補助金制度より強くなりうる点は、主張と現実の乖離を多層で測れることにある。

不正やゲーム化は、単独の指標だけを見ると隠れる。
しかし、次を同時に見ると異常値として出やすい。

```text
申請された成果
実際の行動row
類似集団との比較
反実仮想からの残差
短期成果と長期副作用
平均値と下位層の分布
主観指標と客観アンカー
活動量と構造成果
ledger上の重複claim
```

たとえば、相談件数だけが急増しているのに、制度利用、就労接続、生活安定、撤退率、本人納得が動かない場合、それは構造持続価値ではなく、活動量の水増しである可能性が高い。

同じように、企業の持続指標だけが改善し、個人、家系、地域、自然の持続指標が悪化している場合、それは改善ではなく転嫁である。

このため、発行やペナルティは、単発のスコアではなく、乖離監査を通した後に扱う。
実行用の乖離監査候補は `domain_packs/agi_youth_japan/data/structure_sustain_anomaly_audit.tsv` に置く。

## 計算式の位置づけ

次の式は、正式な通貨発行式ではなく、構造持続価値を考えるための最小の読み方である。
ある介入や活動 `a` について、介入なしの反実仮想と比較する。

```text
構造側nat = B_baseline - B_after
```

`B_after` が小さくなれば、純消耗が減ったことを意味する。
つまり、未来の維持可能経路がより多く残った、または修復されたと読む。

資源側 `M` も含めるなら、

```text
log(S_after / S_baseline)
  = log(M_after / M_baseline) - (B_after - B_baseline)
```

を使う。

通貨発行量は、推定値をそのまま使わず、検証係数をかける。

```text
発行可能nat
  = max(0, log(S_after / S_baseline))
    * 寄与率
    * 検証信頼度
    * 持続性係数
    * 外部不経済控除
```

この `発行可能nat` に、制度が定める交換係数をかける。

```text
発行額 = 発行可能nat * 円換算係数
```

ただし、この段階で重要なのは、係数を確定することではない。
重要なのは、何を `X` とし、何を `G` とし、どの維持可能領域を増やすことを価値とするかを、事前に指定できることである。

科学的・数学的に計測できる部分が増えるほど、構造持続通貨は単なる思想ではなく、制度設計として強くなる。
逆に、計測できない部分を無理に通貨化すると、ただのスローガンや恣意的補助金になる。

## 重要な違い

構造持続通貨は、次のものではない。

- ボランティア時間への単純報酬
- 行政が良いと思った活動へのポイント配布
- GDPの代替指標を雑に通貨化したもの
- LLMが良い活動だと判定したものへの自動支払い
- 既存制度を維持するためだけの保守報酬
- すべてを一つの幸福指標に還元する制度

見るべきものは、活動後に `G` を満たせる未来経路が本当に増えたかである。

そして、どの系を最大化するかは必ず明示する。
個人の持続を高める活動が、家系や自然を壊す場合がある。
企業の持続を高める活動が、社会や個人を壊す場合もある。
したがって、構造持続通貨は単一スコアを盲目的に最大化するものではなく、多層の系のあいだで、どの維持条件を同時に守るかを設計する仕組みである。

## ペナルティの考え方

構造持続通貨には、正の発行と同じくらい、負の会計が重要である。

もしある活動が、売上や短期効率を増やしても、指定された系の維持可能領域を大きく縮小するなら、それは構造持続価値を生んでいない。
むしろ、将来の修復費用や社会的損傷を外部化している。

```text
プラス発行:
  維持可能領域を広げる、修復経路を増やす、不可逆損傷を防ぐ

ペナルティ:
  維持可能領域を極端に狭める、修復経路を潰す、不可逆損傷を増やす
```

ペナルティ対象の例:

| 行為 | どの系を落とすか |
|---|---|
| 若手育成を切り、短期利益だけを上げる | 個人、企業、社会 |
| ケア負担を家族へ押し戻す | 個人、家系、社会 |
| 申請負荷を上げて支援から人を遠ざける | 個人、家系、社会 |
| 地域医療・交通・教育の撤退を放置する | 家系、社会、国家 |
| 自然の回復不能な損傷を利益化する | 自然、社会、国家 |
| 国家安全保障の名目で市民の修復経路や権利を潰す | 個人、社会、国家 |

このペナルティは、道徳的に悪いから罰するという発想ではない。
指定した系の構造持続性を大きく落とす外部不経済を、会計上の負債として扱うという発想である。

## ペナルティ設計の注意

ペナルティは強力なので、濫用を防ぐ規律が必要である。

| 規律 | 理由 |
|---|---|
| 対象系と維持条件Gを事前指定する | 後から気に入らない行為を罰しないため |
| 極端な低下だけを対象にする | 小さな揺らぎや正当な挑戦を萎縮させないため |
| 反実仮想と比較する | 外部環境の悪化を一主体の責任にしないため |
| 複数レイヤーを見る | 企業だけ守って個人や自然を壊すことを防ぐため |
| 修復機会を残す | ペナルティが撤退や隠蔽を生まないようにするため |
| 透明な異議申し立てを持つ | 誤計測や政治利用を防ぐため |

構造持続通貨は、挑戦や変化を止める制度ではない。
むしろ、変化しながら維持条件を壊さないための制度である。
そのため、ペナルティは「失敗したから罰する」のではなく、「指定した系の回復不能な損傷を外部化したとき」に限定する。

特に重要な追加制約は次である。

- 個人単位の負のnatは原則禁止する
- 合法な抗議や批判は、制度修復シグナルとして扱い、ペナルティ対象にしない
- 結婚、出産、家族形成は実績ではなく、望む人が選択できる実効性だけを見る
- 修復すれば何でも軽減できるわけではなく、不可逆損傷や権利侵害は相殺禁止にする
- ペナルティ負担は意思決定者や受益主体へ帰着させ、利用者・若者・住民・ケア受益者へ転嫁しない

## 今回のAGI若者ドメインでの読み

今回の系は、厳密には日本社会全体ではなく、次の構造維持問題として切る。

```text
X:
  AGI時代の日本における若者、家族形成世代、現役世代、組織、国家圧力を含む社会状態

G:
  若者と子ども世代が、役割、学習、仕事、住居、ケア、家族形成、制度利用、修復経路を持ち、
  未来を自分たちで作れると感じられる条件
```

この場合、構造持続通貨の発行対象は、たとえば次のようになる。

| 活動 | 通貨化する理由 |
|---|---|
| 学び直しから移行雇用へつなぐ | 役割再獲得経路を増やす |
| 介護・子育て・地域ケアを支える | 家族形成と社会参加の両立経路を残す |
| 学校・企業・地域を接続する | 若者の未来経路と自己効力感を増やす |
| 地域医療・交通・通信を維持する | 地方で暮らす選択肢を消さない |
| 制度利用の申請負荷を下げる | 修復経路へ到達できる人を増やす |
| AI導入と若手育成を両立する | 自動化で役割を失うだけの経路を避ける |

## シミュレーション上の扱い

LLMエージェントは、通貨発行額を直接決めない。
LLMに任せるのは、個人、組織、国家が、与えられた情報のもとでどう感じ、どう動くかの観測である。

通貨発行は、別レイヤーで行う。

```text
イベント/施策
  -> LLMエージェント反応
  -> 感情・行動row
  -> 集団反応
  -> 構造維持条件Gごとの指標更新
  -> B, M, S の推定
  -> 反実仮想との差分
  -> 発行可能nat
```

この分離が重要である。
LLMが「これは良い活動」と言ったから支払うのではなく、凍結された維持条件、指標、比較シナリオに対して、構造持続ポテンシャルが改善したときに支払う。

今回のハッカソンでは、通貨制度そのものを完成させる必要はない。
むしろ見るべきなのは、次の問いである。

```text
もし、指定した系の構造持続性を高めることが仕事になり、
それで飯が食える社会制度になったら、
人、企業、国家はどう行動を変えるのか。
```

この問いをシミュレーションできることが、今回の文明OSデモの強いポイントになる。

## 反実仮想が必要な理由

構造持続通貨では、単に良い状態になっただけでは発行しない。
比較対象が必要である。

```text
介入なしなら B がどれだけ悪化していたか
介入ありで B がどれだけ抑えられたか
```

この差分が価値になる。

たとえば、若者の希望指数が上がっても、それが偶然の景気回復によるものなら、特定施策への通貨発行対象ではない。
逆に、希望指数が大きく上がらなくても、撤退や制度不信の連鎖を止め、将来経路を残したなら、構造持続価値は発生しうる。

## ゲーム化を防ぐ規律

通貨化すると、必ず最適化と悪用が起きる。
そのため、最低限次の規律が必要である。

| 規律 | 理由 |
|---|---|
| `G,V,m,時間地平` を事前固定する | 後から都合よく価値を作れないようにする |
| 反実仮想を固定する | 自然回復や外部要因を自分の成果にしない |
| 外部不経済を控除する | ある層の経路を増やして別の層の経路を潰すことを防ぐ |
| 二重計上を禁止する | 同じ修復を活動時間、成果、波及で三重に売らない |
| 負の発行または返還を持つ | 後から構造消耗が判明した場合に調整する |
| 脆弱層への寄与を別枠で表示する | 平均だけ改善して取り残しを隠すことを防ぐ |
| LLM判定を最終審査にしない | 生成の説得力と検証を混同しない |

複数レビューで特に危険とされた穴は次である。

| 穴 | 対応するガードレール |
|---|---|
| 反実仮想を盛って発行額を作る | 反実仮想事前登録 |
| 壊してから直す方が儲かる | 追加性・自己原因除外 |
| 平均改善で弱い層の悪化を隠す | 分布下限・少数派保護 |
| 高リスク層を避ける | 反チェリーピック補正 |
| ペナルティが政治利用される | 統治分離、手続保障、合法抗議の非ペナルティ |
| 個人や家族が監視対象になる | 個人監視禁止 |
| 長期価値を短期に先取りする | 遅延ベスティング |
| 形式的な研修や相談件数だけ増える | 品質ゲート |
| 発行しすぎて通貨信用が崩れる | 通貨信用ガードレール |

実行用のガードレール候補は `domain_packs/agi_youth_japan/data/structure_sustain_guardrails.tsv` に置く。

## 最大化対象を間違えない

「系の最大化」と言うと、既存制度を長持ちさせることだけが目的に見える危険がある。
構造持続通貨で最大化したいのは、既存体制の保存ではない。

最大化するのは、次である。

```text
人が役割を持ち直せる経路
壊れた制度を修復できる経路
次世代を迎えられる経路
弱い立場の人が排除されない経路
環境変化に応じて構造を更新できる経路
```

したがって、監視、強制、排除、権利縮小によって短期安定を高めるものは、構造持続価値として扱わない。
それは `G` の設計段階で除外する。

## 仕事になるとは何か

構造持続通貨が成立すると、仕事の定義が少し変わる。

既存の市場では、誰かが買うもの、利益になるもの、短期で測れるものが仕事になりやすい。
構造持続通貨では、まだ壊れていない構造を守ること、壊れかけた経路を修復すること、次世代が使う経路を準備することも仕事になる。

| 現在は仕事になりにくい活動 | 構造持続通貨で仕事化される理由 |
|---|---|
| 家族介護の調整、休息確保、相談接続 | 個人と家系の修復経路を残す |
| 若者の進路相談、地域企業との接続 | 若者の未来経路を増やす |
| 中小企業の技能継承、若手育成 | 企業と地域の維持可能領域を広げる |
| 申請手続きの簡素化、制度翻訳 | 社会の修復経路への到達率を上げる |
| 災害前の地域関係づくり | ショック後の回復可能性を上げる |
| 生態系・水・土壌の回復活動 | 自然系の不可逆損傷を防ぐ |

この設計が実現すると、仕事は「市場で売れる活動」だけではなく、
「指定した系の持続可能領域を増やす活動」でも成立する。

## 家族介護・出産・子育ての扱い

この構想では、家族介護、出産、子育ては、家庭内で勝手に背負う私的負担ではなく、家系、社会、次世代を維持する構造持続活動として扱える。

家族介護では、介護する人が仕事、学習、休息、健康、社会参加を失わないことが重要である。
そのため、家族が介護を担う場合でも、次のような支払いが成立しうる。
ただし、長時間介護への歩合報酬ではなく、所得喪失の補填、上限付きの時間保障、代替ケア利用、復職・復学経路とセットで扱う。

- 介護時間への所得補償
- 休息・代替ケアの利用権
- 介護調整、通院付き添い、制度申請への報酬
- 家族内の一人に負担が集中しないための支援
- 介護者の学習・就労復帰経路の保証

出産・子育てでは、子どもを持つこと自体を国家や制度が命令するのではない。
評価対象は、望む人が、所得、住居、医療、時間、保育、教育、地域支援を通って、安心して子どもを迎えられる実効性である。

したがって、支払いの対象は「出生数の成果報酬」ではなく、次のような構造条件である。

- 妊娠・出産期の所得保障
- 産前産後の医療・休息・移動支援
- 育児時間への所得補償
- 保育・教育・住居・医療への実費支援
- パートナーや家族に偏らないケア分担
- 子育て後の就労・学習復帰経路
- 子ども本人の健康、学習、関係、安心の維持

つまり、出産・子育てでお金が入るというより、
出産・子育てによって失われがちな所得、時間、キャリア、健康、住居安定を、社会が構造維持コストとして引き受ける。

ここでも `家族形成非強制` は必須である。
非婚、非出産、単身、同性カップル、養育しない選択をペナルティ対象にしてはいけない。
通貨化するのは、選択の結果ではなく、望む人が選べる経路を残すことである。

出生数と介護時間は、診断用の遅行指標として扱う。
直接の報酬単位にするのは、出生数や介護時間ではなく、家族形成・ケア実行可能領域の改善、代替経路の充足、子ども本人と被介護者本人の安全・尊厳の維持である。

## ハッカソンでの見せ方

発表では、いきなり `S = M e^{-B}` を主役にしない。
まずは次のように言う。

```text
このシミュレーターは、施策によって人の感情や行動がどう変わるかだけでなく、
指定した系の持続可能性が増えるかを見ます。

最終的には、個人、家系、企業、社会、国家、自然のどの系でも、
維持・修復・継承に貢献する活動が経済的に報われる仕組みにしたい。
```

デモでは、次の比較を出すとよい。

| 比較 | 見せるもの |
|---|---|
| 介入なし | 未来経路が閉じ、生活防衛と諦念が増える |
| 介入あり | 一部の経路が修復され、制度利用、学び直し、ケア継続、連帯が増える |
| 通貨化の仮想 | どの活動が構造持続価値として発行対象になりうるか |

## 実装上の次の一手

まずは通貨発行式を確定するのではなく、どの系を最大化対象にするかを明確にする。

1. 個人、家系、企業、社会、国家、自然の各レイヤーを `Pi=(X,G)` として定義する
2. 各レイヤーで、何が増えたら構造持続性が上がったと言えるかを置く
3. 今回のAGI若者デモでは、若者、家族形成、組織、国家の4レイヤーに絞る
4. 介入なし/介入ありrunで、感情と行動がどの持続レイヤーへ効くかを見る
5. 同時に、指定した系の持続を極端に落とす行為をペナルティ候補として記録する
6. 発表では、通貨発行額ではなく「この活動が仕事化されうる理由」と「この外部不経済にペナルティが必要な理由」を見せる

この段階では、これは本物の通貨ではない。
制度設計として使えるか、どこで副作用や不公平感が出るかをシミュレーションするための設計である。
