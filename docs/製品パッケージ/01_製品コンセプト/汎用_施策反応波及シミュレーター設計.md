# 汎用 施策反応・波及シミュレーター設計

## 目的

このプロジェクトは、一回限りの未来デモではなく、特定の制度設計・施策・社会介入を打ったときに、人の感情、行動、集団反応、社会状態がどう変わるかを事前検証するための汎用シミュレーターとして設計する。

狙いは、次の問いに答えること。

- どのような人が、どのような感情になる可能性があるか
- その感情が、どのような行動へつながるか
- 個人の行動が、連帯、反発、離脱、制度利用、抗議、生活防衛などの集団反応へどう波及するか
- 集団反応が、次の社会状態や政策環境をどう変えるか
- 施策の意図した効果だけでなく、副作用、遅延効果、反作用、格差拡大を事前に検出できるか

## 一文で言うと

施策案を入れると、複数タイプの人間エージェントがどう感じ、どう動き、それが社会全体にどう跳ね返るかをLLMで事前観測するシミュレーター。

## 位置づけ

今回の「AGI時代の若者・現役世代・国家モデル」は、この汎用シミュレーターの1テーマである。

```text
汎用 施策反応・波及シミュレーター
  ├─ テーマパック: AGI/シンギュラリティと若者の未来感情
  ├─ テーマパック: 少子化政策
  ├─ テーマパック: 地方創生/地域インフラ
  ├─ テーマパック: 企業制度/人事制度
  ├─ テーマパック: 教育制度
  └─ テーマパック: 医療・介護制度
```

## 基本構造

```text
テーマ定義
  -> 施策・制度案
  -> 対象集団・エージェント設計
  -> 背景状態・世界イベント・国内イベント
  -> LLMエージェント観測
  -> 個人感情・行動row
  -> 集団反応集約
  -> 社会状態フィードバック
  -> 次ステップへ継承
```

## 入力レイヤー

| レイヤー | 内容 | 例 |
|---|---|---|
| テーマ定義 | 何を検証するか | AGIと若者、少子化、地域制度、人事制度 |
| 施策定義 | 何を打つか | nat報酬制度、住宅支援、学び直し保証、ケア賃金底上げ |
| 対象集団 | 誰が影響を受けるか | 若者、現役世代、子育て世帯、非正規、地方住民 |
| エージェント属性 | 人物の固定条件 | 年齢、地域、所得、雇用、住居、負債、ケア責任 |
| 心理・認知傾向 | 情報の受け取り方 | 制度信頼、自己効力感、SNS感受性、リスク回避 |
| 状態変数 | その時点の社会状態 | 雇用不確実性、生活コスト、財政余力、制度信頼 |
| 世界イベント | 背景として起きる出来事 | AI競争、地政学緊張、物価変動、災害、技術事故 |
| 施策実装条件 | 施策が届く条件 | 対象範囲、予算、申請負荷、周知、実装速度 |
| 証拠・仮定 | 現実妥当性の根拠 | 統計、先行研究、歴史事例、専門家仮説 |

## 出力レイヤー

| 出力 | 意味 | 使い道 |
|---|---|---|
| 個人感情 | 主感情、評価分類、感情強度 | 誰が安心/不安/怒り/諦念になるか |
| 個人認知 | 知覚状況、反応根拠、持ち越し懸念 | なぜそう感じたかを説明する |
| 個人行動 | 行動カテゴリ、具体行動、発信内容 | 行動変化・制度利用・撤退を観測する |
| 集団反応 | 連帯、反発、離脱、抗議、制度要求 | 系全体の波及を見る |
| 社会状態更新 | 次ステップの環境変化 | 行動が社会へ戻る閉ループを作る |
| 副作用 | 意図しない負の効果 | 不公平感、逆選択、情報過敏、制度不信 |
| 意思決定指標 | 施策比較に使う集約値 | 安定性、希望、参加、撤退圧、制度信頼 |

## LLMの役割

LLMは、正解を出す神ではなく、条件を与えられた人物モデル・組織モデル・国家モデルの反応を観測する推論器として使う。

禁止すること:

- 「この施策は効く」と結論を命令する
- 「この人を希望にする」と感情を命令する
- 発表上都合のよいストーリーをなぞらせる
- 施策の副作用を隠す

許可すること:

- 属性、状態、記憶、施策条件、世界イベントを渡す
- 出力形式を指定する
- 感情分類、行動分類、数値範囲を指定する
- 反応しない、誤解する、怒る、諦める、利用する、連帯するなどの自然な分岐を許す

## 感情分類と行動分類はテーマから分離する

感情分類と行動分類は、テーマごとに差し替え可能な辞書として扱う。

今回の基本辞書:

| 評価 | 感情 |
|---|---|
| 良好 | 安心、希望、連帯感 |
| 中立 | 平静 |
| 注意 | 不安、怒り |
| 危険 | 裏切られ感、喪失感、絶望、諦念 |

行動分類:

| 行動カテゴリ | 意味 |
|---|---|
| 静観 | 大きく動かず様子を見る |
| 情報収集 | 調べる、ニュースを見る、相談先を探す |
| 相談 | 友人、家族、先生、同僚、窓口へ話す |
| 生活防衛 | 節約、副業、支出削減、現状維持 |
| 回避・縮小 | SNS回避、計画延期、活動縮小 |
| 学習・就活 | 訓練、応募、資格、進路変更 |
| 制度利用 | 支援申請、制度問い合わせ |
| 参加・連帯 | コミュニティ参加、相互扶助 |
| 抗議・発信 | SNS投稿、署名、デモ、批判 |
| ケア継続 | 家族・地域ケアを優先する |
| 撤退 | 就労、学習、結婚、子育て、社会参加から離れる |

## 波及・フィードバック設計

個人rowをそのまま眺めるだけでは、施策の系全体への影響は見えない。
個人行動を集約し、社会状態へ戻す。

```text
個人row
  -> 行動カテゴリ別に集計
  -> 人口重み・発信影響重みを適用
  -> 集団反応圧力を算出
  -> 社会状態を更新
  -> 次ステップのLLM入力へ戻す
```

集団反応圧力:

| 圧力 | 例 |
|---|---|
| 撤退圧 | 就活停止、進学断念、子ども意向低下、社会参加低下 |
| 制度要求圧 | 支援申請、抗議、政策要求、説明責任要求 |
| 生活防衛圧 | 消費縮小、副業化、家計防衛 |
| 学習移行圧 | 再教育、職業転換、スキル投資 |
| 連帯圧 | 地域活動、相互扶助、共同プロジェクト |
| 情報過敏圧 | SNS不安拡散、怒り増幅、誤情報影響 |
| ケア圧 | 家族ケア集中、離職、地域負担 |

## 施策の評価観点

| 観点 | 見るもの |
|---|---|
| 直接効果 | 対象者の希望、安心、制度利用が増えるか |
| 副作用 | 非対象者の不公平感、怒り、制度不信が増えないか |
| 波及効果 | 連帯、学習、制度要求、生活防衛がどう広がるか |
| 遅延効果 | 数ステップ後に効く/悪化する効果があるか |
| 分配効果 | 都市/地方、所得、雇用、ケア責任で差が出るか |
| 説明可能性 | なぜその結果になったかをrow単位で説明できるか |
| 意思決定可能性 | 施策A/B/Cの比較に使える指標が出るか |

## 実行方式

ローカルモデル前提にはしない。
モデル実行部は抽象化し、複数バックエンドを差し替え可能にする。

| 実行方式 | 例 | 用途 |
|---|---|---|
| API | OpenAI API、Anthropic API、Gemini API | 本番実行、ログ管理、再現性 |
| サブスクCLI | ChatGPT/Claude/Gemini系CLI | ハッカソン、個人開発、低コスト検証 |
| ローカルモデル | Ollama等 | 機密検証、小規模・低品質での事前確認 |
| ルールベース | 係数更新 | LLMなしの高速比較、感度分析 |

重要なのは、シミュレーター本体が特定モデルに依存しないこと。

```text
Simulation Core
  -> Model Adapter
      -> OpenAI API
      -> Claude API
      -> Gemini API
      -> Claude CLI
      -> ChatGPT CLI
      -> Local model
      -> Rule-based fallback
```

## 情報収集モード

ユーザーがテーマや施策案だけを持っている場合、LLMが入力設計を補助する。

```text
ユーザーのアイデア
  -> 論点抽出
  -> 対象集団候補
  -> 状態変数候補
  -> 感情・行動分類候補
  -> 背景イベント候補
  -> 証拠・仮定リスト
  -> ユーザー確認
  -> シミュレーション設定
```

この情報収集LLMは、シミュレーション本体のエージェントとは分ける。
情報収集LLMは設計補助者。
シミュレーションLLMは人物/組織/国家の反応観測器。

## 再現性の考え方

LLMを使うため完全な決定論にはしない。
ただし、再現性を高めるために次を保存する。

- 入力TSV
- プロンプトテンプレート
- モデル名
- 実行方式
- 実行日時
- 各ステップのraw response
- rowデータ
- 実行ログ
- 乱数seed相当の設定
- 監査レポート

## 監査

生成後に必ず監査する。

| 監査項目 | 内容 |
|---|---|
| ステップ完全性 | 必要なステップがすべてあるか |
| エージェント完全性 | 各ステップに対象エージェントが揃っているか |
| イベント完全性 | 背景イベント/施策イベントが不足していないか |
| 数値変動 | 状態変数が固定されすぎていないか |
| 過剰イベント | 同じイベントが毎ステップ乱発されていないか |
| 説明整合 | 感情・行動・根拠が矛盾していないか |
| 副作用検出 | 怒り、撤退、反発、不公平感が観測されているか |
| 比較可能性 | 施策なし/あり、施策A/Bで比較できるか |

## ハッカソンでの言い方

このデモは「未来予測」ではなく、「制度案への人間反応と社会波及を事前に観測するためのシミュレーション基盤」である。

予測の正確さだけを主張するのではなく、

- 誰に効くか
- 誰に効かないか
- 誰が怒るか
- 誰が離脱するか
- どこで連帯が生まれるか
- どの反応が次の社会状態を悪化/改善するか

を、施策実行前に検討できることを価値にする。
