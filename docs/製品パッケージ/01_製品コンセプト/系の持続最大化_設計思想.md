# 系の持続最大化 設計思想

## 一文

このプロジェクトの中心思想は、単一KPIを最大化することではなく、指定した系の維持可能領域を広げ、修復経路を残し、次世代へ渡せる条件を増やすことである。

## 発表用のまとめ

資本主義は、商品、労働、資本、信用のように価格へ変換できる価値を増やす力が強い。
一方で、子どもを迎えられる条件、介護する人が壊れない条件、若者が未来経路を持てること、地域や自然が回復できること、制度への信頼が残ることは、価格に乗りにくい。

構造持続通貨の発想は、この価格に乗りにくい価値を「善意」や「自己犠牲」のまま放置せず、個人、家系、企業、社会、国家、自然という複数の系が続けられる条件を広げた分として会計に載せることである。

```text
いまの経済:
  売れるもの、利益が出るもの、短期で成果が見えるものに報酬が集まりやすい

構造持続通貨:
  壊れる前に守る、壊れた経路を直す、次世代へ渡せる条件を増やすことにも報酬を出す
```

つまり、構造持続通貨は資本主義を否定するものではない。
資本主義だけでは拾いきれない維持、修復、ケア、継承、回復可能性を、別の価値発行レイヤーとして足す構想である。

このとき大事なのは、「良いことをした人にポイントを配る」ことではない。
指定した系が、変化やショックを受けても維持、修復、更新、継承できる範囲が本当に広がったかを見る。

## 何を最大化するのか

最大化したいのは、出生数、介護時間、GDP、利益、制度利用件数、相談件数、研修参加数のような単独指標ではない。

最大化したいのは、次である。

```text
指定した系が、変化やショックを受けても、
同じ系として維持・修復・更新・継承できる経路の広さ
```

構造持続理論の言葉では、対象を `Pi=(X,G)` として読み、
`G` を満たせる状態、行動、経路の集合 `V` がどれだけ残るかを見る。

## なぜ単一KPIではだめか

単一KPIは、すぐに暴走する。

| 単一KPI | 起きる暴走 |
|---|---|
| 出生数 | 望まない出産圧力、非出産者への不利益、子ども本人の条件軽視 |
| 介護時間 | 家族介護の固定化、女性・若者への負担集中、代替ケア抑制 |
| 利益 | 育成・ケア・自然・地域への外部不経済 |
| 制度利用件数 | 申請件数や相談会だけ増える形式成果 |
| 制度信頼 | 抗議や批判を構造消耗として扱う危険 |
| 国家安定 | 権利制限や排除による短期安定の偽装 |

だから、指標は診断に使う。
通貨発行や報酬の単位にするのは、単独指標ではなく、維持可能領域の改善である。

## 診断指標と報酬単位を分ける

出生数や介護時間は重要な観測値である。
しかし、それ自体を直接の報酬単位にしない。

```text
出生数:
  診断用の遅行指標
  直接の成果報酬単位ではない

介護時間:
  負担量や必要支援量を知る診断指標
  長いほど報酬が増える歩合指標ではない
```

報酬単位に近いのは、次である。

```text
望む人が子どもを迎えられる実効条件
子ども本人が安全に育つ条件
介護者が壊れない条件
被介護者が尊厳を保てる条件
家族以外にも代替ケアがある状態
復職・復学・休息・相談の経路
```

## 多層の系を同時に見る

系は一つではない。
個人、家系、企業、社会、国家、自然が重なっている。

したがって、ある系の持続性を上げても、別の重要な系を壊すなら、それは構造持続価値ではない。

```text
企業が儲かるが、個人と自然を壊す
国家が安定するが、市民の修復経路を閉じる
家系が維持されるが、若者一人にケア負担が固定される
出生数が増えるが、子ども本人や親の条件が壊れる
```

このような場合、発行ではなく、控除、保留、ペナルティ、または設計見直しになる。

## 構造持続通貨の基本原則

構造持続通貨の基本原則は、次の順番で考える。

1. まず壊してはいけない下限を守る
2. 不可逆損傷を他の改善で相殺しない
3. 個人の権利、選択、抗議、医療情報をスコア材料にしない
4. 反実仮想、G、V、m、時間地平を事前登録する
5. 単一スコアではなく、レイヤー別ベクトルで見る
6. 平均ではなく、下位層・少数派・未到達者を見る
7. 壊してから直す方が儲かる構造を禁止する
8. 長期価値は遅延検証し、すぐ全額発行しない
9. 乖離監査で、申請成果と実測rowのズレを見る
10. 発行額より先に、制度が壊れないかを検証する

## 設計時に注意したこと

この設計で一番避けたいのは、構造持続という名前で別の暴走を作ることである。
そのため、設計時には次を強く分ける。

| 注意点 | 意味 |
|---|---|
| 診断指標と報酬単位を分ける | 出生数、介護時間、相談件数を直接の成果報酬にしない |
| 個人を罰しない | 子どもを持たない、介護しない、抗議する、休むという選択をマイナス評価しない |
| 条件に支払う | 出産そのものではなく、望む人が子どもを迎えられる条件に支払う |
| 壊れない介護に支払う | 家族介護の固定ではなく、所得、休息、代替ケア、尊厳維持に支払う |
| 弱い人を材料にしない | 困っている人をスコア獲得の対象物にしない |
| 平均改善で隠さない | 全体平均が良くても、脆弱層、少数派、地域、自然の床割れを失敗として扱う |
| 壊してから直す方が得にしない | 自己原因の損傷、後出し成果、二重計上を発行対象から外す |
| LLMに最終決定させない | LLMは反応観測、抜け漏れ検出、説明補助に使い、権利制限や発行確定は任せない |
| 金融の持続性も見る | natが増えても、物価、供給制約、財政、債務が壊れるなら成功にしない |
| 異議申し立てを残す | 価値定義、監査、ペナルティには人間の異議申し立て経路を置く |

短く言えば、最大化したいのは「国家や企業に都合のいい安定」ではなく、人が壊れず、制度が直せて、自然や次世代に負債を押しつけない形の持続性である。

## LLMと科学の使い方

LLMは価値を決める裁判官ではない。
LLMは、多様な主体の反応、抜け漏れ、副作用、違和感を観測するために使う。

科学・統計・実証研究は、価値判断を消すものではない。
価値判断を公開し、測れる部分を検証可能にし、支持・非支持・沈黙を分けるために使う。

自動化は、二重計上、後出しbaseline、異常値、乖離を見つけるために使う。
人間の権利制限やペナルティ確定を自動化しない。

## 制度ストレステスト用エージェント

人口代表エージェントとは別に、制度の穴を探すための機能エージェントを置く。
これは「日本に何人いるか」を代表するものではなく、制度設計を壊し得る視点を代表する。

見るべき視点は、少なくとも次である。

```text
受益者: 本当に生活や選択肢が広がるか
支援者: 現場負担や制度運用が壊れないか
企業: 採用、投資、価格転嫁、育成判断がどう変わるか
行政: 予算、監査、政治的説明が成立するか
ゲーム化探索者: 不正、二重計上、抜け道がないか
監査者: 申請成果と実測rowの乖離を検出できるか
市民社会: 監視、排除、自己責任化への反発が起きないか
金融・物価: 円給付、供給制約、インフレ、金融安定に耐えるか
```

通常ステップで毎回全員を回す必要はない。
ただし、制度導入、ペナルティ設計、出産・介護支援、金融制約、反対運動、長期検証の局面では、必要な視点だけを呼び出して制度を壊す方向からも観測する。

## 今後の議論で使う合言葉

迷ったときは、次の問いに戻る。

```text
それは、どの系の維持可能領域を広げているのか？
別の系を壊していないか？
単一KPIを最大化していないか？
弱い人をスコアの材料にしていないか？
壊してから直す方が得になっていないか？
その価値定義は誰が決め、誰が異議申し立てできるのか？
```

この問いに答えられないものは、構造持続通貨の発行対象にしない。
