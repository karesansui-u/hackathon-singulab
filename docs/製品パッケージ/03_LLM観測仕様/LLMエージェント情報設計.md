# LLMエージェント情報設計

## 目的

このシミュレーションでLLMにやらせたいことは、設計者が望む物語をなぞらせることではない。
エージェント属性、生活制約、記憶、世界状態、日本社会状態を渡し、その人物モデルが自然にどう更新されるかを観測する。

```text
命令:
  不安になれ
  怒れ
  学習しろ
  希望を下げろ

情報:
  こういう人物である
  こういう生活制約がある
  前ステップでこう感じていた
  今ステップの世界と日本社会はこうである
  その人が知覚しそうな情報環境はこうである
```

LLMは、後者の情報から状態更新を推定する。

## エージェントに渡す情報

| 情報層 | 内容 | 扱い |
|---|---|---|
| 固定属性 | 年齢、性別、地域、所得、雇用、住居、負債、ケア責任 | 人物の変わりにくい条件 |
| 心理傾向 | SNS感受性、リスク回避、時間割引、自己効力感、制度信頼 | 情報をどう受け取りやすいか |
| 初期状態 | 主感情、未来経路開放度、構造支援度、感情強度 | シミュレーション開始時の状態 |
| 過去記憶 | 前ステップの内心、行動、持ち越した懸念 | 連続性を作る材料 |
| 世界状態 | 国家LLM由来の地政学、エネルギー、雇用、財政、SNS不安 | 世界圧力 |
| 日本社会状態 | 緩衝政策余力、財政制約、社会反応イベント | 国内環境 |
| 情報環境 | SNS、友人、職場/学校、家族から知覚しそうな空気 | 本人が実際に見る世界 |

## 出力は「観測項目」

出力項目は、エージェントへの命令ではなく、観測者が記録するrowデータである。

| 出力 | 意味 |
|---|---|
| evaluation | 4分類ルーム上の現在位置 |
| emotion | そのステップの主感情 |
| pathway | 本人から見た未来経路の開放度 |
| support | 本人から見た構造支援感 |
| intensity | 感情の強さ |
| action_category | 観測された行動の分類語彙 |
| action_detail | 実際にしそうな具体行動 |
| thought | 内心 |
| private_talk | 友達や近い人への言い方 |
| social_post | 見られる前提の短い発信 |
| perceived_situation | 本人がこのステップで何を知覚したか |
| reasoning_basis | なぜその反応になったかの根拠 |
| memory_update | 次ステップに残る記憶 |
| carryover_concern | 次ステップへ持ち越す懸念 |

## 創発を出すための原則

- 大きな世界圧力があっても、全員が反応する必要はない。
- 反応しない、見ないふりをする、別の生活課題を優先することも自然な反応として扱う。
- 同じ情報でも、怒り、撤退、生活防衛、学習、制度利用、連帯に分岐してよい。
- 数値はイベント方向に機械的に動かさない。本人の生活文脈から自然な範囲で変わる。
- 前ステップの記憶がある場合、それを無視しない。ただし人間なので矛盾や揺れはあってよい。
- きれいな政策説明ではなく、実際の人が言いそうな未整理さを残す。

## プロンプト上の禁止

- 「このイベントでは希望を下げる」のように、結果を直接指定しない。
- 「この人は怒るべき」のように、感情を指定しない。
- 「政策が効くことを示す」のように、発表上望ましい結論を指定しない。
- エージェント本人へ説教、助言、指示をしない。

## プロンプト上の許可

- 出力JSON形式は指定する。
- 分類語彙は指定する。
- 観測項目の意味は指定する。
- 数値範囲は指定する。
- 「自然でなければ反応しない」「属性により分岐する」は指定する。
