# 100年観測 発表用メモ

このメモは、100年版シミュレーションを発表で使うための補助資料。
研究結果の中心ではなく、最後に示唆として見せる。

## 位置づけ

100年観測で言いたいことは、100年後を正確に当てたという主張ではない。

言いたいことは次である。

```text
観測のパラダイムが変われば、
制度設計は単年度KPIや短期費用対効果だけでなく、
制度が世代を越えて「希望の経路」として残るかまで試せる。
```

これは予測精度を競うパートではなく、制度設計の観測対象を広げるパートである。

## 発表で使える一文

```text
これは予言ではありません。
でも、観測の単位を変えると、制度の評価対象が変わります。
今年のKPIだけでなく、制度が世代を越えて希望の経路として残るかを試せる。
そこに、観測のパラダイムシフトとしての希望があります。
```

短く言う場合:

```text
100年後を当てるのではなく、
100年後にも未来経路が残る制度かを、事前に観測するためのデモです。
```

## 数字の読み方

この結果は、楽観的なハッピーエンドではない。
100年後も不安は強く残っている。

ただし、発表で重要なのはここである。

- 危険層は0.0%のまま
- 絶望や社会からの撤退ではなく、情報収集、制度利用、改善要求として社会に接続している
- 未来経路と構造支援は、5年目より40年目以降のほうが高い
- 不安が残ること自体は現実的であり、むしろ都合よすぎる結果になっていない

つまり、この実行結果は「全員が幸福になる」ではなく、
「不安があっても、制度にアクセスし、改善を要求し、社会から離脱しない経路が残った」と読む。

## スライドでの見せ方

100年版は、メインデモの後に15-20秒だけ見せる。

おすすめの流れ:

1. 5年目を見せる
2. 40年目を見せる
3. 100年目を見せる
4. 数字を細かく説明しすぎず、最後の一文で締める

締めの言い方:

```text
不安は消えていません。
でも、絶望や撤退ではなく、制度を使う、情報を集める、改善を求める行動として残っている。
このように、短期のKPIでは見えない「希望の経路」を観測できるようにすることが、このシミュレーターの狙いです。
```

## 審査員に聞かれたときの答え

| 質問 | 答え |
|---|---|
| 100年後を予測しているのか | 予測ではなく、制度が長期にどう記憶されるかを見る示唆パート |
| 結果が都合よすぎないか | 良好層が増えているわけではなく、不安は強く残る。現実寄りの結果 |
| なぜ希望と言えるのか | 不安があっても危険・撤退に落ちず、制度利用や改善要求として社会接続が残っているため |
| LLMに希望を命令していないか | 分類・row形式は固定するが、各エージェントの感情、発言、行動は属性と状態入力から生成している |
| 構造持続理論との関係は | お金だけでなく、役割、修復経路、未来経路が残るかを観測するという思想が背景にある |

## 注意

100年目の表示は、90年目に若者として流入した制度記憶世代が25歳になった状態を含む。
そのため、発表では「100年後の若い世代」「制度記憶を受け取った世代」と言うのが安全。
文字通り「100年後の15歳」を見せたい場合は、100年目に追加流入する世代テンプレートを別途追加する。
