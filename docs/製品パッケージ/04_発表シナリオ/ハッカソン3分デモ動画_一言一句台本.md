# ハッカソン3分デモ動画 一言一句台本

この台本は、3分デモ動画でそのまま読み上げる前提の文言である。
主張は強くするが、未来予測や創発の過剰主張にならないようにする。

## 冒頭の一文

```text
これは、未来を当てるAIではありません。
制度が人間にどう届き、どこで詰まり、どの設計で行動が変わるかを、LLMエージェントで事前にデバッグするシミュレーションです。
```

## 3分デモ動画 台本

### 0:00-0:15 タイトル

画面:
タイトル画面。未来感のあるヘッダーと、シミュレーションUIの全体像を短く見せる。

ナレーション:

```text
今回作ったのは、AGI社会への移行期に、若者や家族形成世代が未来の選択肢を持てるのかを検証する、制度設計シミュレーションです。
```

### 0:15-0:40 問い

画面:
介入なしの画面。マップ、SUMMARY、Live Voiceを見せる。

ナレーション:

```text
制度は、作っただけでは機能しません。
人がそれを知り、信じ、予約し、相談し、実際に使うところまで進まなければ、効果は社会に届きません。
そこで私たちは、制度そのものではなく、制度が人間の生活と感情と行動に変換される過程を観測対象にしました。
```

### 0:40-1:10 LLMエージェント設計

画面:
エージェント詳細、Live Voice、内心・友達トーク・行動のタブを見せる。

ナレーション:

```text
各エージェントは、年齢、家計、住居、雇用、ケア責任、制度信頼、SNS影響、過去の記憶を持っています。
毎ステップ、世界イベントと制度介入を受けて、感情、行動、内心、友達との会話、SNS発信、次に残る不安を更新します。
LLMを自由な会話キャラとして使うのではなく、属性と状況に対する反応をrowデータとして出す観測器として使っています。
```

### 1:10-1:35 介入なし

画面:
シミュレーション選択を「新通貨制度なし」または「介入なし」にする。
SUMMARYとLive Voiceを見せる。

ナレーション:

```text
まず、制度側の追加介入を置かない場合です。
AGIやAIロボの普及、生活コスト、地政学不安、SNS悲観、医療や介護の負荷が進む中で、エージェントは不安、生活防衛、制度不信を強めます。
ここでは、希望があるかないかだけではなく、どのイベントが撤退圧や制度要求に変わるかを見ています。
```

### 1:35-1:58 出産支援のみ

画面:
シミュレーション選択を「出産支援のみ」にする。
子ども希望指数、SUMMARY、代表エージェントを見せる。

ナレーション:

```text
次に、子育て初期一時金1000万円の出産支援のみを置いた場合です。
金銭支援は一部の不安を下げます。
しかし、住居、仕事、ケア、制度への信頼、相談できる相手が弱いままだと、子どもを持つ選択は十分には戻りません。
ここで見えてくるのは、お金だけではなく、制度を使える状態まで設計する必要があるということです。
```

### 1:58-2:35 構造持続通貨 + 制度利用伴走支援

画面:
シミュレーション選択を「構造持続通貨 + 制度利用伴走支援」にする。
マップの改善、Live Voice、地域プロジェクト参加や相談のrowを見せる。

ナレーション:

```text
最後に、構造持続通貨と制度利用伴走支援を組み合わせます。
これは単なる給付ではありません。
地域、ケア、教育、防災、制度更新のような、社会を持続させる活動に報酬が流れるインセンティブ設計を置きます。
さらに、通知、予約、自動着金、メンター、相談導線によって、制度が存在するだけでなく、使える状態になるかを見ます。
rowデータ上では、制度利用、相談、参加・連帯への行動変化が観測されます。
```

### 2:35-2:50 何が新しいか

画面:
rowデータ、マップ、Live Voice、SUMMARYを短く切り替える。

ナレーション:

```text
このシステムの価値は、制度案を出すことではありません。
制度が人間にどう受け取られ、どこで詰まり、どの補助設計で行動が変わるかを、実施前に比較できることです。
いわば、制度設計の事前リハーサルです。
```

### 2:50-3:00 転用と締め

画面:
企業人事制度、自治体施策、学校、地域などの転用先を短く表示する。

ナレーション:

```text
この仕組みは、自治体政策だけでなく、企業の人事制度変更、退職防止、採用、福利厚生、学校や地域施策にも転用できます。
未来を予言するのではなく、制度が社会に出る前に、人間の反応経路を観測する。
それが今回のデモです。
```

## スライド用 そのまま使える文言

### Slide 1 タイトル

```text
制度が社会に出る前に、人間の反応をシミュレーションする。
```

サブコピー:

```text
AGI社会移行における若者・家族形成世代の行動変化を、LLMエージェントで事前観測する制度設計AI
```

### Slide 2 問い

```text
AIによって仕事、家計、家族形成、地域、制度信頼が同時に揺れる未来に、
若者は「自分にも次の選択肢がある」と思えるのか。
```

### Slide 3 課題

```text
多くの制度設計は、金額や対象者を決めて終わってしまう。
しかし現実では、制度があることと、制度が使われることは違う。
人が知り、信じ、予約し、相談し、実際に使うまでの経路がなければ、制度は社会に届かない。
```

### Slide 4 作ったもの

```text
世界イベント、制度介入、エージェント属性を入力すると、
人々の感情、行動、内心、会話、SNS発信、制度利用をrowデータとして観測し、
介入前後の社会反応を比較できるシミュレーターを作りました。
```

### Slide 5 技術設計

```text
LLMを自由会話キャラとしてではなく、属性と状況に対する反応を生成する観測器として使います。
出力は、感情、行動カテゴリ、具体行動、内心、友達との会話、SNS発信、反応根拠、持ち越し懸念を持つ固定スキーマのrowデータです。
```

### Slide 6 比較する3つのシナリオ

```text
1. 介入なし
   世界圧力と生活不安がそのまま進む比較基準。

2. 出産支援のみ
   子育て初期一時金1000万円を置くが、制度利用の導線は限定的。

3. 構造持続通貨 + 制度利用伴走支援
   社会を持続させる活動に報酬を流し、通知、予約、着金、メンター、相談導線まで設計する。
```

### Slide 7 デモで見えること

```text
見るのは、単なる楽観・悲観ではありません。
不安が生活防衛に変わるのか。
制度不信が相談に変わるのか。
通知と予約と着金によって、制度利用に進むのか。
地域プロジェクト参加のような、社会に残る行動へつながるのか。
```

### Slide 8 何が新しいか

```text
これは未来予測AIではありません。
制度設計の事前デバッグです。
施策が人間の生活、感情、信頼、行動にどう変換されるかを、現実に実施する前に観測します。
```

### Slide 9 転用

```text
今回のテーマはAGI社会の若者と家族形成ですが、仕組みは汎用です。
エージェント、イベント、感情辞書、行動辞書、評価指標を差し替えれば、
企業の人事制度変更、自治体施策、学校改革、地域政策にも使えます。
```

### Slide 10 締め

```text
制度を作るだけではなく、制度が人間にどう届くかまで設計する。
この観測ができれば、政策も、人事制度も、社会実装の前に副作用と詰まりを検証できます。
```

## 審査員に刺す短い表現

```text
LLMに「こう反応しなさい」と命令するのではなく、属性、状態、イベント、制度情報、過去記憶を渡し、反応を観測しています。
```

```text
制度の効果を、金額だけではなく、知る、信じる、予約する、相談する、使う、参加するという行動経路で評価しています。
```

```text
今回のrowデータ上で言えるのは、支え合いが自然発生したという断定ではありません。
社会を持続させる活動への報酬設計と伴走導線を置いたことで、制度利用、相談、参加・連帯への行動変化が観測された、ということです。
```

```text
配布されたシミュレーターの「イベント、エージェント、空間、行動」という骨格を、物理空間の避難ではなく、心理・制度空間の反応観測へ抽象化しました。
```

## 避ける言い方と言い換え

| 避ける言い方 | 言い換え |
|---|---|
| 未来を正確に予測します | 反応経路と副作用を事前に観測します |
| 支え合いが自然発生しました | 支え合いが起きる条件をインセンティブ設計として置き、行動変化の芽を観測しました |
| LLMが社会を再現しています | 属性と状況に対する反応仮説をrowデータとして生成しています |
| この政策が正解です | 施策案の比較材料を作ります |
| お金を配れば解決します | 金銭支援に加えて、制度利用の導線と信頼形成が必要であることを比較します |

```text
制度は、発表された瞬間に効くのではありません。
人が知り、信じ、使い、周囲に伝わり、次の行動に変わったときに初めて社会に届きます。
私たちはその過程を、LLMエージェントで観測できるようにしました。
```
