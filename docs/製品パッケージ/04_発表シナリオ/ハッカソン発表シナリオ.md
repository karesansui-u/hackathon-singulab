# ハッカソン発表シナリオ

## 発表の一文

制度や施策を実行する前に、人々がどう感じ、どう動き、その反応が社会全体へどう跳ね返るかをLLMエージェントで事前検証するシミュレーターです。

## ハッカソン文脈での見せ方

このハッカソンでは、もともと火災シミュレータがベースとして配られている。
そのため、発表では「ただ別テーマにした」ではなく、次の変換を明確に見せる。

```text
火災シミュレータ:
物理空間で火災が起き、人がどう避難・協調するかを見る

今回の拡張:
心理・制度空間で社会ショックが起き、人がどう希望・不安・怒り・行動へ移るかを見る
```

評価されるべきポイントは、単にUIを変えたことではない。
配布された「2D空間・イベント・エージェント・会話」という骨格を、制度設計シミュレーターへ抽象化した点である。

| 元の火災シミュレータ | 今回の読み替え |
|---|---|
| 2D物理空間 | 未来への心理・制度空間 |
| 火災イベント | 世界イベント、制度イベント、社会ショック |
| 避難・移動 | 感情分類ルームへの遷移 |
| 匿名に近いエージェント | 年齢、地域、所得、雇用、ケア責任を持つ代表エージェント |
| 近接会話 | 内心、友達との会話、SNS発信 |
| 混雑や避難行動 | 生活防衛、制度利用、抗議、連帯、撤退 |
| 物理的な安全 | 未来経路、役割、制度信頼、構造支援 |

この変換により、ハッカソンのベース課題を保ちながら、社会制度・企業制度・行政施策にも転用できる汎用フレームへ広げた、と説明する。

## 伝えるべき核

今回見せるものは、単なる未来予測AIではない。
また、LLMに自由に物語を作らせるデモでもない。
さらに、構造持続理論を聞き手が知っている前提にしない。

見せるべき核は次である。

```text
施策・世界イベント・社会状態を入力する
  -> 属性を持つ人間/国家エージェントが反応する
  -> 感情と行動がrowデータとして出る
  -> 集団反応へ集約される
  -> 次の社会状態へ戻る
```

つまり、制度設計とシナリオ予測に使う、創発反応の観測装置である。

構造持続理論は、冒頭で主役として説明しない。
聞き手にはまず、次の直感から入る。

```text
社会は、お金や制度が残っているだけでは続かない。
人が役割を持てること、次の一手を選べること、
壊れた制度を直せる経路が残っていることが必要である。
```

そのうえで、発表の後半または補足で、
この設計思想の背景に構造持続理論がある、と紹介する。

| 避ける言い方 | 理由 | 言い換え |
|---|---|---|
| 未来を正確に予測します | 予測精度の過剰主張になる | 反応経路と副作用を事前に観測します |
| LLMが社会を完全再現します | 現実再現の過剰主張になる | 属性・状態・イベントに対する反応仮説を生成します |
| AGIで人類がこうなります | テーマが広すぎる | AGI時代の制度設計が若者の未来感情にどう効くかを試します |

| 構造持続理論では... | 初見の聞き手が置いていかれる | お金だけでなく、未来の経路が残っているかを見ます |

## ユーザー案ベースの発表骨子

発表の大枠は次でよい。
ただし、思想を先に広げすぎず、「問い -> 直感 -> 作ったもの -> デモ -> 汎用化」の順に絞る。

```text
タイトル:
構造持続理論ベースの新しい文明OSシミュレーション

問い:
AIによって二極化する未来に、我々はどう希望を見出すか

なぜやるのか:
資本主義は価値創造を加速する一方で、
格差、役割喪失、将来不安を生むことがある。
AIはその性質をさらに極端にする可能性がある。

直感:
社会は、お金や制度が残っているだけでは続かない。
人が役割を持てること、未来への経路が開いていること、
壊れた制度を直せることが必要。

作ったもの:
制度や施策を打ったときに、
人の感情・行動・集団反応・社会フィードバックが
どう変わるかを事前に試せるシミュレーター。

デモ:
介入なしでは、不安、生活防衛、撤退圧がどう広がるかを見る。
介入ありでは、役割、支援、連帯、未来経路がどう回復するかを見る。

製品化:
AGI若者専用ではない。
企業、行政、学校、自治体、サークルでも、
エージェント、イベント、感情/行動辞書、評価指標を差し替えれば使える。
```

## デモの見せ方

発表時にLLMを実行しない。
事前に生成したrowデータをUIで再生する。

理由:

- 発表中のAPI/CLI事故を避ける
- 同じ結果を何度も再生できる
- rowデータを見せることで、再現性と説明可能性を示せる
- LLM生成とUI再生を分けることでプロダクト構造が伝わる

デモ順:

1. 最初の状態を見せる
2. 世界イベントが発生する
3. 4部屋マップ上でエージェントが移動する
4. 代表者をクリックする
5. 内心、友達との会話、SNS、行動を見る
6. 左カラムの4分類サマリーと分布を見る
7. これは1人の物語ではなく、人口重み付きの社会反応であると説明する

## 100年観測の見せ方

100年版は、研究結果の中心にしない。
発表の最後に、示唆的な余韻として見せる。

詳細な数字、話し方、想定質問への答えは [100年観測_発表用メモ.md](100年観測_発表用メモ.md) に残す。

ここで伝えるべき希望は、100年後を正確に当てられるという話ではない。
観測のパラダイムが変われば、制度設計は単年度KPIや短期費用対効果だけでなく、次のような問いまで扱えるようになる、という話である。

```text
この施策は、いま困っている人を一時的に助けるだけで終わるのか。
それとも、次世代が生まれた時から使える制度記憶として残るのか。
100年後の若い世代が、自分にも未来経路があると思える社会条件を残せるのか。
```

100年観測パートの言い方:

```text
これは予言ではありません。
でも、観測の単位を変えると、制度の評価対象が変わります。
今年の予算が足りたか、今年のKPIが上がったかだけではなく、
制度が世代を越えて「希望の経路」として残るかを試せる。

もしこの観測のパラダイムシフトが起きれば、
資本主義の短期最適化だけでは見落としていたものを、
制度設計の前に見られるようになる。
そこに希望があります。
```

デモ結果の読み方は、楽観的なハッピーエンドに寄せすぎない。
不安が残っていても、絶望や社会からの撤退へ落ちず、情報収集、制度利用、改善要求として社会に接続し続けているなら、それ自体を「希望経路が残っている状態」として説明する。

## デモ用ナレーション

```text
ここでは世界イベントが直接若者に命令しているわけではありません。
国家エージェントが世界圧力を作り、それが日本社会状態へ変換されます。
その状態を見た若者・現役世代エージェントが、属性や生活制約に応じて反応します。

たとえば同じ物価上昇でも、都市の正規雇用者と、地方で家計制約のある高校生では反応が違います。
この人は不安になり、生活防衛としてバイトを増やすか迷っています。
内心では不安が強いが、SNSでは少し短く、見られる前提の言い方になります。

この反応を人口重み付きで集約すると、生活防衛圧、撤退圧、制度要求圧などが出ます。
それが次の社会状態へ戻り、次のステップの入力になります。
```

## 質疑応答の想定

| 質問 | 回答方針 |
|---|---|
| これは本当に予測できるのか | 一点予測ではなく、反応経路と副作用の事前検証です |
| LLMが勝手に物語を作っているだけでは | 出力形式、分類辞書、属性、状態、イベント、フィードバックを固定し、rowとして監査します |
| 現実データは使っているのか | 初期エージェント、人口重み、イベント、係数に出典・仮定を紐づけ、今後は統計校正を強化します |
| なぜ4分類なのか | 発表UIでは意思決定しやすい粗さにし、内部では主感情10分類を保持しています |
| 30人で日本を表せるのか | 30人は代表エージェントで、人口重みを持つ縮図です。増やすより先に分類と重みの妥当性を監査します |
| SaaS化できるのか | このrepoはGPLの研究デモとして扱い、SaaS本体は別実装で作る方針です |
| 構造持続理論とは何か | お金や人が残っていても、役割、未来経路、修復経路が閉じると構造は続かない、という考え方です |
| 今回どこまで理論を実装しているのか | 理論全体ではなく、推定レイヤーの試作です。若者の希望、不安、行動、撤退圧などを、未来経路が狭まっているかの観測指標として扱っています |

## 構造持続理論との接続

発表では、構造持続理論を聞き手が知っている前提にしない。
理論名を冒頭の主役にせず、まず直感で説明する。

推奨順:

```text
1. 社会課題
若者が未来の選択肢を持てなくなっているかもしれない

2. 直感
お金や制度が残っていても、未来への経路や役割が閉じると、人は希望を持ちにくい

3. デモ
世界イベントや制度変更で、誰の未来経路が開く/閉じるのかを可視化する

4. 背景
この考え方の背景に、構造持続理論という自分の理論がある
```

口頭では次のように短く言う。

```text
社会は、お金や資源が残っているだけでは続きません。
人が役割を持てること、未来への経路が開いていること、
壊れた制度を直せることが必要です。
このシミュレーターでは、その「構造が持続できる条件」が
人々の感情と行動にどう現れるかを観測します。
```

より短い版:

```text
構造持続理論を一言で言うと、
資源量だけでなく、維持・修復・更新できる経路が残っているかを見る考え方です。
```

今回のデモの位置づけ:

```text
今回のデモは、構造持続理論の厳密な仕様固定レイヤーではなく、
現実社会に近い推定レイヤーの試作です。

若者の希望、不安、制度信頼、行動、撤退圧、生活防衛圧などは、
LやBそのものではなく、未来経路が狭まっているかを読むための観測指標です。
```

`nat` は発表では次の位置づけに留める。

```text
将来的には、社会や環境を維持する行動の価値量を定量化し、
報酬や制度設計に接続したい。
今回のデモでは、その前段として、どの行動が構造持続に寄与するかを観測しています。
```
