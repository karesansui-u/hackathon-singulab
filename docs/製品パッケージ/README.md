# 製品パッケージ

このディレクトリは、プロダクトとしての正本に近い設計書を置く場所。

ここに置くもの:

- プロダクトコンセプト
- 汎用シミュレーター設計
- ドメインパック仕様
- 実装アーキテクチャ
- LLM観測プロトコル
- ハッカソン発表シナリオ

ここに置かないもの:

- 実行入力TSVの大群
- 生成済みrowデータ
- rawデータ
- 事前調査メモ
- 発表用の一時加工物
